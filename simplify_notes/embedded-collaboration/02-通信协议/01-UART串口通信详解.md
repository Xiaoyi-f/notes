# 01 - UART 串口通信详解——最基础、最可靠的通信方式

---

## 一、什么是 UART？

**UART = Universal Asynchronous Receiver/Transmitter**
         通用        异步           接收器    发送器

**一句话理解**：UART 就是两台设备之间用两根线「一根发、一根收」互相传数据的方式。就像两个人用对讲机说话，你按一下说一句话，对方听到后回复。

```
┌──────────┐                    ┌──────────┐
│  设备A   │    TX ───────► RX  │  设备B   │
│          │◄─── RX    TX ─────│          │
└──────────┘                    └──────────┘

TX = Transmit（发送）
RX = Receive（接收）

注意：A的TX接B的RX，A的RX接B的TX（交叉连接）
```

**为什么先学 UART？**
- 最古老、最基础、几乎所有芯片都支持
- 硬件简单，只需要2根数据线（+1根地线）
- 调试必备，几乎所有嵌入式设备都留串口用于打印日志
- 理解了 UART，其他通信协议都更容易理解

## 二、UART 的物理连接

### 最简单的情况：两个设备直连

```
┌──────────┐              ┌──────────┐
│  ESP32   │              │  传感器  │
│          │              │          │
│  GPIO17  │── TX ────────┼──► RX   │
│  GPIO16  │◄─ RX ────────┼─── TX   │
│  GND     │── GND ───────┼─── GND  │
└──────────┘              └──────────┘

ESP32（主控）          温湿度传感器（从设备）
TX发命令 ─────────► RX收命令
RX收数据 ◄───────── TX发数据
GND地线 ──────────► GND地线（共地，电压参考）
```

```

│  GND     │─────────────►│  GND       │──────────►│          │
└──────────┘              └────────────┘           └──────────┘
```

## 三、UART 的通信参数——"对讲机的频道设置"

两个设备用 UART 通信，必须设置完全相同的参数，否则就像两个人调在不同频道，互相听不懂。

### 1. 波特率（Baud Rate）

```
波特率 = 每秒传输的二进制位数（bit/s）

常见波特率：
  9600   → 每秒传 9600 位 ≈ 960 字节/秒
  19200  → 每秒传 19200 位
  38400  → 每秒传 38400 位
  57600  → 每秒传 57600 位
  115200 → 每秒传 115200 位 ≈ 11KB/秒（最常用！）
  921600 → 很快，用于大批量数据传输

类比：
  波特率就像说话的速度
  9600 = 慢慢说，每个字很清楚
  115200 = 正常语速
  921600 = 飞快地说，容易听错
```

### 2. 数据位（Data Bits）

```
每个字节（8位）实际传输时，会加上起始位和停止位：

传输一个字节 'A'（ASCII码 0x41 = 01000001）：

    起始位  D0  D1  D2  D3  D4  D5  D6  D7  停止位
    │       │   │   │   │   │   │   │   │   │
    ▼       ▼   ▼   ▼   ▼   ▼   ▼   ▼   ▼   ▼
    0       1   0   0   0   0   0   1   0   1
    │       └────── 8个数据位 ──────────┘   │
    │                                        │
  低电平                                    高电平
  (表示开始)                               (表示结束)

数据位通常是 8 位（1个字节）
```

### 3. 停止位（Stop Bits）

```
停止位 = 数据传输结束后的高电平持续时间

1位停止位：┌────┐
           │数据│   │
           └────┘   │
                    │
                    ▼
                 1位高电平

2位停止位：┌────┐
           │数据│       │
           └────┘       │
                        │
                        ▼
                     2位高电平

用途：给接收方时间处理数据
通常用 1 位停止位即可
```

### 4. 校验位（Parity）

```
校验位 = 用来检查数据传输是否出错的额外一位

奇校验（Odd）：数据位中1的个数 + 校验位 = 奇数
偶校验（Even）：数据位中1的个数 + 校验位 = 偶数

例子：传数据 0b10100101（里面有4个1）
  偶校验：已经有4个1（偶数），校验位 = 0
  奇校验：已经有4个1（偶数），校验位 = 1（凑成奇数）

接收方收到后数一下1的个数，如果不符合约定，就知道传错了。

实际使用中：通常用 None（无校验），因为现代通信很可靠
```

### 5. 完整参数配置

```
┌─────────────────────────────────────────┐
│         串口配置（最常见的设置）          │
├─────────────────────────────────────────┤
│  波特率：115200                         │
│  数据位：8                              │
│  停止位：1                              │
│  校验位：None（无）                      │
│  流控：None（无）                        │
└─────────────────────────────────────────┘

简称：115200 8N1
```

## 五、用串口助手实操

### 1. 连接硬件

```
ESP32开发板 ──USB线──► 电脑

注意：开发板上已经有 USB转TTL 芯片，不需要额外的串口模块
直接插USB线就行！
```

### 2. 打开串口助手（SSCOM / XCOM）

```
┌────────────────────────────────────────────┐
│  SSCOM 串口助手                             │
│                                             │
│  端口：COM3  ◄── 选择ESP32对应的串口号       │
│  波特率：115200                             │
│  数据位：8                                  │
│  停止位：1                                  │
│  校验位：None                               │
│                                             │
│  [打开串口]                                 │
│                                             │
│  ───── 接收区 ─────                         │
│  Temperature: 25.5°C                        │
│  Humidity: 60%                              │
│  Temperature: 25.6°C                        │
│  ...                                        │
│                                             │
│  ───── 发送区 ─────                         │
│  [LED_ON]                                   │
│  [发送]                                     │
└────────────────────────────────────────────┘
```

### 3. 常见串口助手功能

| 功能 | 说明 | 用途 |
|------|------|------|
| 发送文本 | 输入字符串发送 | 发送控制命令 |
| 发送十六进制 | 输入 `AA 55 01 00` 发送 | 发送二进制协议 |
| 自动发送 | 定时循环发送 | 测试设备响应 |
| 保存日志 | 把接收的数据存文件 | 记录长时间数据 |
| 显示时间戳 | 每条数据前加时间 | 分析时序 |

## 六、UART 的优缺点

```
┌─────────────────────────────────────────────┐
│              UART 的优点                      │
├─────────────────────────────────────────────┤
│ ✅ 硬件简单，只需要2根数据线                  │
│ ✅ 几乎所有芯片都支持                         │
│ ✅ 全双工（可以同时收发）                      │
│ ✅ 无需时钟线（异步，各自用自己的时钟）          │
│ ✅ 点对点通信，确定性强                        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│              UART 的缺点                      │
├─────────────────────────────────────────────┤
│ ❌ 只能点对点，不能一对多（不像I2C/SPI）        │
│ ❌ 没有设备地址，连多个设备需要多路复用          │
│ ❌ 速度较慢（最高约 1Mbps）                    │
│ ❌ 距离有限（几米内，受干扰会丢数据）            │
│ ❌ 没有内置的错误纠正机制                      │
└─────────────────────────────────────────────┘
```

### Electron 中通过串口通信的代码

```typescript
// Electron 主进程中使用 serialport 库
import { SerialPort } from 'serialport'

// 列出可用串口
const ports = await SerialPort.list()
console.log(ports)  // 看到 [{ path: 'COM3', manufacturer: 'Silicon Labs' }, ...]

// 打开串口
const port = new SerialPort({
  path: 'COM3',
  baudRate: 115200,
  dataBits: 8,
  stopBits: 1,
  parity: 'none'
})

// 接收数据
port.on('data', (data: Buffer) => {
  console.log('收到:', data.toString())
  // 收到的可能是："Temperature: 25.5\r\n"
})

// 发送数据
port.write('LED_ON\n')
```
