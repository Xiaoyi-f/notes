# 01 - 条件编译与平台差异处理

> UniApp 的精髓：一套代码，通过条件编译适配不同平台。

---

## 一、条件编译语法

```vue
<template>
  <view>
    <!-- #ifdef H5 -->
    <text>这段只在 H5 显示</text>
    <!-- #endif -->
    
    <!-- #ifdef MP-WEIXIN -->
    <text>这段只在微信小程序显示</text>
    <!-- #endif -->
    
    <!-- #ifdef APP-PLUS -->
    <text>这段只在 App 显示（iOS/Android）</text>
    <!-- #endif -->
    
    <!-- #ifdef APP-PLUS || H5 -->
    <text>这段在 App 和 H5 都显示</text>
    <!-- #endif -->
  </view>
</template>

<script setup>
// #ifdef H5
console.log('H5环境')
// #endif

// #ifdef MP-WEIXIN
console.log('微信小程序环境')
// #endif

// #ifdef APP-PLUS
// App特有的API
const plugin = uni.requireNativePlugin('PluginName')
// #endif
</script>

<style>
/* #ifdef H5 */
body { background: #f0f0f0; }
/* #endif */

/* #ifdef APP-PLUS */
page { background: #000; }
/* #endif */
</style>
```

## 二、平台判断方法

```javascript
// 获取运行环境
const systemInfo = uni.getSystemInfoSync()
console.log(systemInfo.platform)   // 'ios' / 'android' / 'windows' / 'mac' / 'devtools'
console.log(systemInfo.system)     // 'iOS 16.0' / 'Android 13'
console.log(systemInfo.model)      // 设备型号
console.log(systemInfo.windowWidth)  // 窗口宽度

// 条件编译常量
// #ifdef H5
const isH5 = true
// #endif

// #ifdef MP-WEIXIN
const isWeixin = true
// #endif

// #ifdef APP-PLUS
const isApp = true
// #endif
```

## 三、常用API平台差异

| API | H5 | 微信小程序 | App |
|-----|----|-----------|-----|
| 扫码 | 不支持（需调摄像头） | `uni.scanCode` | `uni.scanCode` |
| 地理位置 | 支持（需浏览器授权） | 支持 | 支持（更精确） |
| 震动 | 部分支持 | `uni.vibrateShort` | 支持 |
| 拨打电话 | 支持（tel:链接） | `uni.makePhoneCall` | 支持 |
| 文件下载 | 支持 | 支持 | 支持（路径不同） |
| 推送通知 | 不支持 | 支持（需订阅） | 支持（原生推送） |

## 四、分享功能适配

```vue
<script setup>
import { onShareAppMessage, onShareTimeline } from '@dcloudio/uni-app'

// 微信小程序 - 分享给朋友
// #ifdef MP-WEIXIN
onShareAppMessage(() => {
  return {
    title: '分享标题',
    path: '/pages/index/index?id=123',
    imageUrl: '/static/share.png'
  }
})

// 微信小程序 - 分享到朋友圈
onShareTimeline(() => {
  return {
    title: '朋友圈分享标题',
    query: 'id=123'
  }
})
// #endif

// App分享
const appShare = () => {
  // #ifdef APP-PLUS
  uni.shareWithSystem({
    type: 'text',
    summary: '分享内容',
    href: 'https://yoursite.com'
  })
  // #endif
  
  // #ifdef H5
  // H5复制链接
  uni.setClipboardData({
    data: 'https://yoursite.com',
    success: () => uni.showToast({ title: '链接已复制' })
  })
  // #endif
}
</script>
```

## 五、支付功能适配

```vue
<script setup>
// 微信支付（小程序 + App）
const wechatPay = async () => {
  try {
    // 先向后端下单获取支付参数
    const res = await orderApi.create({ goodsId: 1 })
    const payParams = res.data.payParams
    
    // #ifdef MP-WEIXIN
    // 小程序支付
    uni.requestPayment({
      provider: 'wxpay',
      ...payParams,
      success: () => {
        uni.showToast({ title: '支付成功' })
      },
      fail: (err) => {
        console.log('支付失败', err)
      }
    })
    // #endif
    
    // #ifdef APP-PLUS
    // App支付
    uni.requestPayment({
      provider: 'wxpay',
      orderInfo: payParams,
      success: () => {
        uni.showToast({ title: '支付成功' })
      }
    })
    // #endif
  } catch (err) {
    uni.showToast({ title: '下单失败', icon: 'none' })
  }
}

// 支付宝支付（App）
const alipay = () => {
  // #ifdef APP-PLUS
  uni.requestPayment({
    provider: 'alipay',
    orderInfo: '从后端获取的支付宝订单字符串',
    success: () => uni.showToast({ title: '支付成功' })
  })
  // #endif
}
</script>
```
