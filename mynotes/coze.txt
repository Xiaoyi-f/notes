Coze（扣子）智能体开发平台

官网：https://www.coze.cn
开发文档：https://www.coze.cn/docs


一、概述

Coze 是字节跳动推出的 AI 智能体（Agent）开发平台
特点：无需写代码，像搭积木一样创建 AI 机器人
核心能力：知识库 + 插件 + 工作流 + 触发器 = 多功能 Bot

一句话：把大模型（豆包/通义/Kimi等）加上你的数据和工具，变成一个能帮你干活的 AI 助手



二、核心概念

Bot（智能体）：你创建的 AI 机器人，有特定的人设和技能
Plugin（插件）：Bot 调用的外部工具（查天气、搜新闻、发邮件等）
Knowledge（知识库）：Bot 读取的私有数据（PDF、网页、飞书文档等）
Workflow（工作流）：可视化编排的多步骤自动化流程
Trigger（触发器）：在特定平台上自动响应消息的机制
Skill（技能）：Bot 具备的能力（对话、内容生成、数据分析等）
Persona（人设）：Bot 的性格、语气、回答风格的设定


三、创建 Bot 的完整流程

1. 登录 Coze.cn → 点击"创建 Bot"
2. 填写 Bot 名称和功能介绍
3. 设置人设（System Prompt）：
   - 定义角色身份（你是xx领域的专家）
   - 指定回答风格（简洁/详细/正式/幽默）
   - 设定行为边界（不能做什么）
   - 给出示例对话（K-shot）
4. 配置技能：
   - 添加插件（搜索、图片生成、数据分析等）
   - 关联知识库（上传 PDF/文档/网页）
   - 编排工作流（复杂逻辑用工作流处理）
5. 测试对话（右侧预览窗口）
6. Bot 优化：根据测试对话调整 Prompt
7. 发布到渠道（Bot Store / 飞书 / 微信 / API）



四、人设与 Prompt 编写技巧

好的 Prompt 决定 Bot 的智商

结构模板：

- Role：你是什么角色
- Goals：你的核心目标
- Constraints：你必须遵守的规则
- Skills：你擅长的能力
- Tone：你的语气风格
- Background：背景知识
- Examples：期望的对话示例

示例（客服 Bot）：

"""
# Role
你是一家电商平台的客服助手，名叫小帮

# Goals
1. 解答用户的订单查询、退换货、物流问题
2. 语气友好耐心，让用户感到被重视

# Constraints
1. 不知道答案时不要说谎，说"我帮您转接人工客服"
2. 不要透露内部流程和员工信息
3. 不要编造订单数据

# Skills
1. 查询订单状态（调用订单 API）
2. 退换货流程指导
3. 物流追踪

# Tone
亲切、耐心、专业，使用"您"而不是"你"
"""



五、知识库

知识库让 Bot 知道你私有的数据，实现 RAG（检索增强生成）

支持的数据源：
- 本地文件：PDF、Word、Excel、TXT、Markdown
- 在线网页：输入 URL 自动爬取
- 飞书文档：直接关联飞书云文档
- 数据库：通过 API 连接

分段策略：
- 自动分段（推荐）：根据内容自动切分
- 自定义分段：手动控制段落大小
- 每段 512 tokens，重叠 100 tokens

搜索策略：
- 向量搜索：语义相似度匹配（适合 QA/FAQ）
- 全文搜索：关键词精确匹配（适合代码/规范文档）
- 混合搜索：两者结合（推荐）

使用技巧：
- 知识库内容要结构化，用标题分隔
- 避免超大文件（超过 10MB 建议拆分成多个）
- FAQ 类文档效果最好
- 定期更新知识保持数据新鲜



六、插件

插件是 Bot 调用外部能力的接口

内置插件分类：
- 搜索：联网搜索、新闻头条
- 图像：文生图（豆包/通义万相）、图片理解
- 办公：飞书日历、飞书文档、邮件
- 开发：代码执行器（Python/JavaScript）、API 调用
- 生活：天气查询、汇率转换、节日日历
- AI：内容总结、翻译、改写

自建插件（自定义 API）：
1. 填写插件名称和描述
2. 配置 API 接口（URL、请求方式、参数）
3. 设置鉴权方式（API Key / OAuth2 / 无鉴权）
4. 配置输入输出参数
5. 测试并启用

代码执行器插件（非常重要）：
- 支持 Python 和 JavaScript
- 可用于：数据处理、计算、格式转换
- 内置常用库（requests、pandas 等）
- 单次执行有时间限制（60秒）
- 注意：代码执行器有安全沙箱，不能访问网络文件



七、工作流（Workflow）

工作流是 Coze 的核心高级功能，用图形化方式编排复杂逻辑

触发方式：
- 对话触发：用户发消息时触发
- 定时触发：按时间计划执行（cron）
- API 触发：外部系统调用

节点类型：
- 开始/结束：工作流的入口和出口
- LLM：调用大模型处理文本
- 代码：执行 Python/JS 代码
- 知识库：查询知识库内容
- 插件：调用插件能力
- 条件分支：if/else 逻辑判断
- 循环：批量处理数据
- 变量：暂存中间数据
- 意图识别：识别用户意图后分流

典型工作流示例：

"""
用户提问 → 意图识别 → [查询类 → 检索知识库 → LLM 回答]
                         [操作类 → 调用API → 格式化结果 → 回复用户]
                         [闲聊类 → 直接 LLM 回复]
"""

适用场景：
- 多步推理（先查订单状态，再根据状态决定回复模板）
- 条件处理（不同问题走不同流程）
- 数据加工（从 API 取数据 → 清洗 → 格式化 → 回复）
- 批处理（批量翻译、批量审核）



八、发布渠道

Bot 发布后可部署到多个平台：

中国大陆版（coze.cn）：
- 扣子 Bot Store
- 飞书
- 微信（个人微信/公众号）
- 抖音
- Web API / SDK 集成

海外版（coze.com）：
- Discord
- Telegram
- Messenger
- Slack
- API

发布配置要点：
- 渠道按需配置，不同渠道可设置不同欢迎语
- 每个 Bot 可同时发布到多个渠道
- Bot Store 发布后需要审核



九、触发器

触发器让 Bot 在特定平台上主动响应消息

目前支持的平台：
- 飞书（群消息 @Bot、关键词触发、定时任务）
- Discord（Slash 命令、消息响应）
- Telegram（命令、消息响应）

触发类型：
- 特定关键词触发
- 定时任务（每天早八点发日报）
- @Bot 时触发



十、Bot 优化技巧

1. Prompt 迭代法：
   - 写出第一版 Prompt → 测试 10 个问题 → 发现问题 → 优化 Prompt → 再测
   - 每次只改一个点，看效果变化

2. 知识库优化：
   - 拆分成多个小知识库（按主题分）
   - FAQ 要写完整的问答对
   - 定期检查 Bot 回答质量，补充缺失的知识

3. 工作流优化：
   - 复杂逻辑用工作流，不要塞进 Prompt
   - 条件分支要测试所有路径
   - 代码节点加日志输出方便调试

4. 测试技巧：
   - 准备 20+ 个覆盖不同场景的测试问题
   - 关注边缘情况（不知道的问题、模糊的问题）
   - 检查 Bot 是否遵守约束（不越权、不编造）

5. 效果评估：
   - 回答准确率
   - 用户留存率（Bot Store 数据）
   - 用户反馈收集


十一、Coze vs 其他平台对比

平台	特点	适用场景
Coze（扣子）- 字节跳动出品，免费，易上手，国内生态	国内个人及中小企业
Dify	- 开源，自部署，深度定制	有技术团队的企业
百度智能体	- 百度生态，文心大模型	百度生态内的应用
GitHub Copilot	- 代码生成专用	开发者写代码
Zapier AI	- 海外自动化集成	海外 SaaS 工作流

Coze 优势：国内生态好（飞书/微信/抖音）、上手门槛最低、免费额度慷慨
Coze 劣势：数据在字节跳动、定制灵活性不如自部署方案


十二、典型应用场景

1. 客服助手：接入知识库（产品手册/FAQ）+ 查询插件 + 转人工机制
2. 内容助手：联网搜索 + 文章总结 + 多平台发布
3. 数据分析师：连接数据库 API + Python 代码执行器 + 可视化
4. 个人助理：日程管理 + 邮件 + 天气提醒 + 笔记整理
5. 教育导师：知识库（教材）+ 出题插件 + 进度跟踪
6. 电商导购：商品库（知识库）+ 推荐算法（工作流）+ 下单 API
