# Electron 跨平台桌面开发 - 完整学习路线

> 使用 Web 技术（HTML/CSS/JavaScript）开发 Windows、Mac、Linux 桌面应用程序。

---

## 学习路线总览

```
第1周：基础入门
  └── Node.js基础 → Electron原理 → 环境搭建 → 第一个窗口 → 主进程与渲染进程

第2周：窗口与界面
  └── 窗口管理 → 自定义标题栏 → 菜单/托盘 → 多窗口通信 → 弹窗对话框

第3周：系统功能
  └── 文件系统 → 剪贴板 → 通知 → 系统信息 → 自动更新 → 开机启动

第4周：数据交互
  └── HTTP请求 → WebSocket → 本地数据库 → 与后端API对接 → 数据持久化

第5周：实战项目
  └── 项目架构 → 登录系统 → 核心功能 → 系统集成 → 优化调试

第6周：打包发布
  └── electron-builder → Windows安装包 → Mac安装包 → Linux安装包 → 自动更新
```

## 核心概念

### 主进程 (Main Process)
- 每个 Electron 应用只有一个主进程
- 就是 `main.js`（或 `main.ts`）
- 可以访问所有 Node.js API
- 负责创建窗口、管理应用生命周期

### 渲染进程 (Renderer Process)
- 每个 BrowserWindow 对应一个渲染进程
- 就是你的前端页面（Vue/React/HTML）
- 默认不能直接访问 Node.js API（安全考虑）
- 通过 IPC 与主进程通信

### 预加载脚本 (Preload Script)
- 在渲染进程加载页面之前执行
- 有权限访问 Node.js API 和 DOM
- 作为安全桥梁，暴露安全的API给前端
- 是主进程和渲染进程通信的推荐方式

### IPC (进程间通信)
- `ipcMain`：主进程端接收/发送消息
- `ipcRenderer`：渲染进程端接收/发送消息
