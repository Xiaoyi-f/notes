node版本要求22及以上
openclaw官方: curl -fsSL https://openclaw.ai/install.sh | bash
基本使用命令:
    /new -> 聊天命令
    /clear -> 聊天命令
    openclaw tui
    openclaw -v
    openclaw -h
    openclaw cron -> remove / disable / enable / run / add / ... <任务ID>
    openclaw config
    openclaw config set
    openclaw status
    openclaw gateway start
    openclaw doctor
    openclaw update
    openclaw dashboard
