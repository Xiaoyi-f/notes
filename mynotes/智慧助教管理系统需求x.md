# 一、项目概述
## 1.1 项目背景
为解决高校辅导员人工管理效率低、家校协同不畅、学生异常行为难预判、咨询响应不及时等痛点，打造一款集“学生管理、家校协同、智能预警、AIGC赋能、虚拟人接待”于一体的全链路数字化思政育人平台。整合学生信息管理、消息通知、问卷填报、学生画像、行为预测、AIGC辅助、AI虚拟人等所有核心功能，实现从“人工管理”向“数据驱动、智能预警、精准育人、高效协同”的升级，覆盖辅导员日常工作全场景，同时满足学生、家长的信息查询与咨询需求。

## 1.2 核心目标
+ 实现辅导员所带全部班级学生、家长信息统一管理，完成学生-家长关联绑定，打通家校协同通道。
+ 支持一键通知学生/家长，实现通知精准触达、状态统计，提升沟通效率。
+ 替代传统在线表格，实现问卷调研、假期流向表等表单的自主填报、自动汇总，减少人工整理成本。
+ 构建360°学生智能画像，基于学生行为数据实现异常行为预测与预警，提前干预风险。
+ 深度融合AIGC能力，实现PPT一键生成学生画像、智能内容创作、数据分析等，赋能辅导员高效办公。
+ 基于辅导员历史对话、情绪、语气，生成专属AI虚拟人，7×24小时接待学生、家长咨询，所有对话永久存档，方便后续查看跟进。
+ 搭建匿名树洞通道，保护学生隐私，助力辅导员掌握学生思想动态，开展精准思政工作。

## 1.3 适用范围
适用对象：高校辅导员（核心用户）、辅导员所带全部班级学生、学生家长；覆盖场景：学生信息管理、家校沟通、通知推送、问卷填报、学生日常考勤请假、学生画像分析、行为预警、AIGC辅助办公、虚拟人咨询、匿名反馈等。

# 二、核心功能需求
## 2.1 学生&家长信息管理模块
### 2.1.1 学生信息管理
+ 基础信息管理：支持批量导入/手动录入辅导员所带全部班级学生信息，包含学号、姓名、班级、宿舍、联系方式、家庭住址等，建立学生唯一档案，支持编辑、删除、筛选。
+ 学生档案维护：为每个学生建立个人中心，整合在校全周期数据（考勤、请假、成绩、奖惩、填报记录等），辅导员可随时查看、编辑、补充档案内容。
+ 多班级统一管理：支持辅导员管理所带全部班级，可按班级、年级、专业等维度筛选、分组管理学生，快速定位目标学生。

### 2.1.2 家长信息管理
+ 家长信息绑定：支持辅导员批量邀请家长加入系统，或学生自主邀请家长，完成学生-家长一对一/多对一关联绑定，支持绑定多个家长联系方式。
+ 家长数据统计：实时统计家长总数、已绑定/未绑定家长数、各班级家长绑定率，生成未邀请家长名单，提醒辅导员跟进。
+ 家长权限管理：精细化配置家长可见内容，可自定义家长是否查看学生成绩、奖惩记录、请假记录、假期流向等信息，防止信息泄露。

## 2.2 消息通知模块
### 2.2.1 通知发送功能
+ 多对象精准发送：支持按「全部班级学生/部分班级学生/指定学生」「全部家长/部分班级家长/指定家长」发送通知，可同时选择学生和家长双对象发送。
+ 通知内容编辑：支持标题、正文编辑，内置语音转文字快捷输入，支持上传附件（文档、图片）、添加网址链接，适配通知、提醒、公告等全场景。
+ 发送配置：支持「无需回复」选项，避免学生/家长回复“收到”造成消息打扰；支持定时发送、重新发送、撤回通知。
+ 通知类型适配：覆盖查寝预告、资料完善提醒、家长邀请、放假提醒、学校通知转发、问卷填报提醒等辅导员日常通知场景。

### 2.2.2 通知接收与统计
+ 接收状态统计：实时统计通知已读/未读人数，生成未读学生/家长名单，支持辅导员一键再次提醒未读人员。
+ 通知历史管理：辅导员可查看所有已发送通知记录，支持删除、撤回、导出通知数据，查看通知发送时间、对象、已读未读详情。
+ 多端触达：通知通过微信公众号/小程序推送，未绑定公众号的学生/家长单独标记，支持辅导员二次手动提醒。

## 2.3 问卷调研与在线填报模块
### 2.3.1 问卷/表单创建与管理
+ 多类型表单支持：支持创建问卷调查、假期流向表、留校报备表、返校报备表、信息登记表等多种表单，替代传统在线表格。
+ 灵活题型配置：支持单选题、多选题、填空题、日期选择、附件上传、地址选择等多种题型，满足不同调研/填报需求。
+ 权限与规则配置：可按「全部班级/指定班级/指定学生」设置填报对象；支持设置填报截止时间、是否允许重复填报、是否匿名填报；可配置问卷置顶展示，方便学生快速找到。
+ 生命周期管理：支持问卷/表单的创建、编辑、发布、暂停、删除，实时查看填报进度和状态。
+ 模板库预设：内置假期流向、返校调研、心理普查等常用模板，辅导员一键复用，无需重复创建。

### 2.3.2 学生端填报功能
+ 一站式填报入口：学生登录个人中心，首页集中展示所有待填报问卷/表单，无需跳转第三方平台，操作便捷。
+ 自主填报与进度保存：学生可直接在系统内完成填写、提交，系统自动保存填报进度，支持中途退出后继续填写，避免重复操作。
+ 填报提醒：未完成填报的学生，系统自动推送提醒，辅导员可一键催填，提升填报率。
+ 历史记录查询：学生可查看自己所有已提交的填报记录，方便追溯、核对。

### 2.3.3 辅导员端数据管理
+ 实时进度统计：实时展示各问卷/表单的已填报/未填报人数，生成未填报学生名单，支持一键催填。
+ 数据自动汇总：所有填报数据自动汇总成表格，支持一键导出Excel，无需手动整理，减少工作负担。
+ 数据可视化分析：自动生成问卷统计图表（选项占比、人数分布等），帮助辅导员快速掌握调研结果和学生情况。
+ 批量管理：支持批量导出数据、批量催填、批量关闭问卷，提升管理效率。

## 2.4 学生管理模块
### 2.4.1 考勤签到管理
+ 多方式签到：支持扫码签到、GPS定位签到、密码签到、拍照签到（可要求全宿舍合拍、指定背景自拍），防止代签。
+ 签到规则配置：辅导员可自定义签到时间、签到范围、签到要求，适配查寝、上课、活动等不同场景。
+ 数据统计与留存：实时统计签到情况，留存签到照片，支持批量预览、导出，到期自动清理过期签到数据。

### 2.4.2 请假管理
+ 线上申请与审批：学生线上提交请假申请，填写请假事由、时间、去向等信息，辅导员在线审核，支持批量审批。
+ 请假记录管理：请假记录全量留存，可按班级、请假事由、时间筛选，支持导出，方便后续核对。
+ 家校同步：家长可查看绑定学生的请假记录（请假事由、时间、审核状态），实现家校信息同步。

### 2.4.3 离校/返校管理
+ 离校全程报备：学生提交离校预约、出发报备、途中报备、到家报备，多节点记录行程，保障学生安全。
+ 返校全程管理：整合返校前健康申报、行程报备、到校签到等流程，学生分阶段填报，辅导员实时监控。
+ 数据统计与预警：实时统计离校/返校报备人数，生成遗漏学生名单提醒，对逾期未报备、逾期未返校学生推送预警。

### 2.4.4 学生奖惩与成绩管理
+ 奖惩记录管理：辅导员录入学生奖励荣誉、处分记录，标注时间、事由，自动同步到学生个人档案和家长端（按权限配置）。
+ 成绩公布：辅导员上传学生成绩，可配置成绩可见范围（仅学生可见、家长可见、仅辅导员可见），支持按班级、科目筛选查看。

## 2.5 匿名树洞（提问箱）模块
### 2.5.1 学生端功能
+ 匿名提问：学生可通过树洞功能，匿名向辅导员提交问题、反馈诉求、倾诉烦恼，全程保护隐私，无需担心身份泄露。
+ 问题分类：支持学生为问题添加标签（学习、生活、心理、评奖评优等），方便辅导员分类处理。
+ 记录查看：学生可查看自己提交的问题及辅导员的回复，实时跟进反馈结果。

### 2.5.2 辅导员端功能
+ 提问管理：统一查看所有学生的匿名提问，支持按时间、标签、处理状态（未处理/已处理）筛选。
+ 回复与标记：可对问题进行回复、标记已处理、置顶重要问题，设置问题可见范围（仅自己可见、所有学生可见）。
+ 数据统计：统计提问数量、高频问题类型，分析学生思想动态，辅助思政工作开展。

## 2.6 学生智能画像与行为预测模块
### 2.6.1 360°学生智能画像系统
+ 画像数据来源：整合学生全维度数据，构建多维度标签体系，数据维度包括基础档案、日常行为（考勤、归寝、活动参与）、学习状态（成绩、考勤）、社交互动、家校互动、心理状态（问卷、树洞）。
+ 画像可视化：为每个学生生成个人画像仪表盘，以图表、标签形式直观呈现学生状态；支持按班级、年级批量查看学生画像，快速定位异常学生。
+ 标签体系：包含基础标签（基本信息）、行为标签（晚归/不归、活动参与度等）、风险标签（高/中/低风险）、成长标签（优秀/进步/需关注），标签随学生行为实时更新。

### 2.6.2 学生行为智能预测与预警系统
+ 核心预测场景：基于机器学习算法，预测以下异常行为： 
    - 晚归/不归预警：分析学生历史归寝时间，预测近期不归寝风险；
    - 集体活动参与度预警：识别长时间不参与班级/学院活动的学生，预测社交孤立风险；
    - 学业风险预警：根据成绩波动、课堂考勤，预测挂科、学业下滑风险；
    - 心理异常预警：结合树洞提问、问卷数据、行为异常，预测心理问题风险；
    - 离校/返校安全预警：预测学生未按要求报备行程、逾期返校风险；
    - 家校失联预警：预测家长长时间不查看通知、不配合家校协同的风险。
+ 预警机制：分为低风险（提醒关注）、中风险（重点跟进）、高风险（立即干预）；系统自动推送预警通知给辅导员，标注风险原因；支持辅导员记录干预措施、跟进结果，形成“预警-干预-跟踪”闭环。
+ 模型优化：支持辅导员手动标注异常行为，反馈预测结果，持续优化算法精度；可自定义预警阈值，适配不同管理需求。

## 2.7 AIGC全场景赋能模块
### 2.7.1 PPT一键生成学生画像报告
+ 核心功能：辅导员一键上传学生数据或PPT课件，AIGC自动生成班级/个人学生画像分析报告PPT。
+ 内容自动整合：自动提取学生行为数据、风险预警、成长情况，生成可视化图表、分析结论，标注重点内容。
+ 模板适配：支持自定义报告模板，自动适配思政工作汇报、家长会汇报等场景，自动生成汇报话术。

### 2.7.2 AIGC智能辅导员助手
+ 智能问答：学生端AIGC智能客服，7×24小时解答常见问题（请假流程、评奖评优等）；辅导员端AIGC助手，解答管理相关问题（思政工作方法、政策解读等）。
+ 智能内容生成：自动生成通知文案、问卷题目、班会PPT、思政教育内容、谈心谈话提纲、家校沟通话术、学期工作总结等。
+ 智能数据分析：自动分析问卷数据、学生行为数据，生成深度分析报告，提炼学生思想动态，给出班级管理建议。
+ 预警辅助：自动解读学生行为预警，生成风险原因分析、干预建议、谈心谈话脚本，跟踪干预效果。

### 2.7.3 AIGC家校协同赋能
+ 个性化沟通内容：针对不同学生情况，自动生成专属家长沟通话术，提升家校沟通效率。
+ 多语言适配：自动翻译家长咨询内容，适配不同地域、文化背景的家长。
+ 学生情况周报：自动生成学生在校情况周报，一键发送给家长，同步学生状态。

## 2.8 AI虚拟人接待与对话存档模块
### 2.8.1 专属虚拟人生成
+ 复刻辅导员特征：自动学习辅导员的历史对话、说话语气、常用话术、情绪习惯、口头禅，1:1复刻专属AI虚拟老师。
+ 虚拟人形态选择：支持文字AI助手（默认）、语音虚拟人（语音对话）、数字人形象（可选头像/虚拟人物），适配不同场景。

### 2.8.2 7×24小时自动接待
+ 咨询范围： 
    - 学生咨询：请假流程、成绩查询、活动通知、作业要求、归寝问题、心理倾诉等；
    - 家长咨询：孩子在校表现、奖惩情况、成绩、请假记录、安全问题、家长会安排等。
+ 核心能力：自动回答常见问题、查询学生相关数据（成绩、请假、奖惩等）、解释学校/班级规则、安抚情绪、引导填报表单、提醒重要事项。
+ 复杂问题转接：当问题超出知识库、情绪激动、涉及隐私或特殊情况，或家长/学生强烈要求找真人时，自动告知“将记录并转告老师”，生成待办提醒推送给辅导员，标记对话为【需人工处理】。

### 2.8.3 对话记录存档与查看
+ 全量存档：每一段虚拟人与学生/家长的对话均自动保存，包含对话人、对话时间、完整聊天内容、虚拟人回答、是否转人工、处理状态。
+ 辅导员后台查看：支持按学生/家长、时间（今日/本周/本月）筛选对话，可标记重要对话、添加跟进备注，支持导出对话记录存档。
+ 智能总结：AIGC自动总结每段对话的核心诉求、情绪状态（正常/焦虑/不满）、是否解决，给出辅导员跟进建议。

### 2.8.4 系统打通
虚拟人可直接调用系统内所有数据（学生画像、行为预警、成绩、请假、填报记录等），实现精准回答，无需辅导员手动干预。

# 四、业务流程
## 4.1 学生&家长入驻流程
1. 辅导员批量导入所带全部班级学生信息 → 2. 辅导员/学生发起家长邀请 → 3. 家长完成绑定 → 4. 辅导员配置家长可见权限 → 5. 学生、家长正常使用系统功能。

## 4.2 通知发送流程
1. 辅导员编辑通知内容 → 2. 选择发送对象（学生/家长） → 3. 配置发送选项（无需回复、定时发送等） → 4. 发送通知 → 5. 系统统计已读/未读人数 → 6. 辅导员一键提醒未读人员。

## 4.3 问卷/填报流程
1. 辅导员创建问卷/表单（可复用模板） → 2. 配置填报对象、时间、权限 → 3. 发布问卷，系统自动推送提醒 → 4. 学生在个人中心自主填报、提交 → 5. 辅导员实时查看进度、一键催填 → 6. 数据自动汇总、导出、分析 → 7. 问卷归档，数据同步学生档案。

## 4.4 学生画像与预警流程
1. 系统自动采集学生全维度数据 → 2. 生成学生智能画像及标签 → 3. 行为预测模型分析数据 → 4. 识别异常行为，触发对应等级预警 → 5. 向辅导员推送预警通知及风险原因 → 6. 辅导员干预跟进，记录处理结果 → 7. 数据反馈模型，持续优化预测精度。

## 4.5 AIGC PPT生成流程
1. 辅导员上传学生数据/PPT课件 → 2. AIGC自动提取数据、分析学生状态 → 3. 生成学生画像报告PPT → 4. 辅导员编辑、调整内容 → 5. 导出PPT用于工作汇报/家长会。

## 4.6 虚拟人接待与对话流程
1. 系统学习辅导员历史对话、语气习惯，生成专属虚拟人 → 2. 学生/家长在系统发起咨询 → 3. 虚拟人自动接待、回答问题、查询数据 → 4. 复杂问题自动转人工，推送待办提醒给辅导员 → 5. 所有对话自动存档 → 6. 辅导员后台查看对话、处理转人工问题、跟进反馈。

## 4.7 匿名树洞流程
1. 学生匿名提交问题并添加标签 → 2. 辅导员查看问题、分类处理 → 3. 辅导员回复问题 → 4. 学生收到回复提醒，查看反馈 → 5. 问题归档，辅导员统计分析高频问题。

# 五、非功能需求
## 5.1 性能需求
+ 并发能力：支持万级学生、家长同时在线，通知发送、填报提交秒级触达。
+ 响应速度：数据加载、画像生成、预警推送延迟≤5秒；AIGC内容/PPT生成响应时间≤10秒；虚拟人对话响应≤3秒。
+ 稳定性：系统7×24小时稳定运行，年可用率≥99.9%，支持批量操作无卡顿。
+ 存储能力：支持学生、家长信息、对话记录、填报数据、画像数据等长期存储，可按需扩容。

## 5.2 安全与隐私需求
+ 数据加密：学生、家长信息、对话记录、成绩、心理数据等敏感信息加密存储，防止数据泄露。
+ 权限管控：严格按角色分配权限，家长仅可查看绑定学生信息，学生仅可查看个人信息，辅导员仅可查看所带学生信息，防止越权访问。
+ 隐私保护：匿名树洞严格脱敏，不泄露学生身份；虚拟人对话不泄露敏感信息；符合《个人信息保护法》《教育数据安全管理办法》，满足等保要求。
+ 操作追溯：所有用户操作日志全留存，可追溯数据访问、修改、删除等操作，便于排查问题。

## 5.3 易用性需求
+ 辅导员端：界面简洁直观，核心功能一键操作（一键通知、一键催填、一键生成PPT等），无需专业技术能力，降低使用门槛；全流程引导提示，关键操作二次确认，避免误操作。
+ 学生/家长端：界面轻量化，适配微信小程序/公众号，操作简单，无需下载APP；待办事项集中展示，一目了然。
+ 虚拟人：对话自然，贴合辅导员语气，响应迅速，操作便捷，学生/家长无需学习即可发起咨询。

## 5.4 兼容性需求
+ 多端适配：支持PC端（辅导员管理后台）、移动端（微信公众号/小程序）访问，适配不同屏幕尺寸。
+ 浏览器兼容：支持Chrome、Edge、Safari等主流浏览器，确保功能正常使用。
