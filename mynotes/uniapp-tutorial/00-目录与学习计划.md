# UniApp 跨平台开发 - 完整学习路线

> 一套代码，发布到 iOS、Android、微信小程序、H5、支付宝小程序、百度小程序、字节跳动小程序、QQ小程序、快应用等多个平台。

---

## 学习路线总览

```
第1周：基础入门
  └── 环境搭建 → Vue3基础 → 第一个UniApp项目 → 项目结构详解

第2周：页面与组件
  └── 页面生命周期 → 基础组件 → 自定义组件 → 条件编译 → 样式适配

第3周：数据交互
  └── HTTP请求 → 数据缓存 → 状态管理(Pinia) → WebSocket实时通信

第4周：跨平台适配
  └── 平台差异处理 → 原生插件 → 地图/支付/推送 → 权限管理

第5周：实战项目
  └── 项目规划 → 登录注册 → 核心功能 → 接口对接 → 优化调试

第6周：打包发布
  └── 微信小程序 → App(Android/iOS) → H5 → 各平台审核上架
```

---

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端框架 | Vue3 + TypeScript（推荐） |
| UI组件库 | uView UI / uni-ui |
| 状态管理 | Pinia |
| 网络请求 | uni.request / luch-request |
| 路由 | uni-app 内置路由 |
| 后端通信 | RESTful API / WebSocket |
| 打包工具 | HBuilderX / CLI |

---

## 发布平台一览

| 平台 | 文件格式 | 打包方式 |
|------|---------|---------|
| 微信小程序 | .zip | HBuilderX一键上传 |
| Android App | .apk / .aab | 云打包/本地打包 |
| iOS App | .ipa | 云打包（需Mac真机调试） |
| H5 | 网页 | 直接部署到服务器 |
| 支付宝/百度/字节/QQ小程序 | 各平台格式 | HBuilderX一键上传 |

---

## 与后端配合架构

```
┌─────────────────┐     HTTP/WebSocket      ┌─────────────────┐
│   用户设备       │  ═══════════════════►  │   云服务器       │
│                 │                        │                 │
│ ┌─────────────┐ │                        │ ┌─────────────┐ │
│ │  UniApp App  │ │◄══════════════════════ │ │ 后端API服务  │ │
│ │  (iOS/Android)│ │     JSON数据响应        │ │ (Java/Node/Go)│ │
│ └─────────────┘ │                        │ └─────────────┘ │
│ ┌─────────────┐ │                        │ ┌─────────────┐ │
│ │ 微信小程序   │ │                        │ │   数据库     │ │
│ └─────────────┘ │                        │ │ (MySQL/Redis) │ │
│ ┌─────────────┐ │                        │ └─────────────┘ │
│ │    H5网页    │ │                        └─────────────────┘
│ └─────────────┘ │
└─────────────────┘
```

前端UniApp负责界面展示和用户交互，所有业务逻辑和数据存储都在云服务器后端完成。
