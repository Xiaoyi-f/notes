# 01 - UniApp 基础组件大全

> UniApp 封装了一套跨平台的基础组件，在编译时会转换为各平台对应的原生组件。

---

## 一、视图容器

### 1. view - 最常用容器（类似 div）

```vue
<template>
  <view class="box">
    <view class="header">头部</view>
    <view class="content">内容区域</view>
  </view>
</template>

<style>
.box { display: flex; flex-direction: column; }
.header { background: #f0f0f0; padding: 20rpx; }
.content { padding: 20rpx; }
</style>
```

### 2. scroll-view - 可滚动视图

```vue
<template>
  <!-- 纵向滚动 -->
  <scroll-view 
    scroll-y 
    class="scroll"
    @scrolltolower="loadMore"
    :scroll-top="scrollTop"
  >
    <view v-for="item in list" :key="item.id" class="item">
      {{ item.title }}
    </view>
  </scroll-view>
  
  <!-- 横向滚动 -->
  <scroll-view scroll-x class="horizontal">
    <view v-for="i in 10" :key="i" class="card">卡片{{ i }}</view>
  </scroll-view>
</template>

<style>
.scroll { height: 800rpx; }
.item { padding: 30rpx; border-bottom: 1rpx solid #eee; }
.horizontal { white-space: nowrap; }
.card { 
  display: inline-block; 
  width: 200rpx; 
  height: 200rpx; 
  margin-right: 20rpx;
  background: #f0f0f0;
}
</style>
```

### 3. swiper - 轮播图

```vue

</style>
```

### 3. picker - 选择器

```vue
<template>
  <view>
    <!-- 普通选择器 -->
    <picker @change="onPickerChange" :value="pickerIndex" :range="pickerArray">
      <view class="picker">当前选择：{{ pickerArray[pickerIndex] }}</view>
    </picker>
    
    <!-- 日期选择器 -->
    <picker mode="date" @change="onDateChange" :value="date">
      <view class="picker">日期：{{ date }}</view>
    </picker>
    
    <!-- 时间选择器 -->
    <picker mode="time" @change="onTimeChange" :value="time">
      <view class="picker">时间：{{ time }}</view>
    </picker>
    
    <!-- 省市区选择器 -->
    <picker mode="region" @change="onRegionChange" :value="region">
      <view class="picker">地区：{{ region.join('-') }}</view>
    </picker>
  </view>
</template>

<script setup>
import { ref } from 'vue'

const pickerArray = ['选项A', '选项B', '选项C']
const pickerIndex = ref(0)
const date = ref('2024-01-01')
const time = ref('12:00')
const region = ref(['北京市', '北京市', '朝阳区'])

const onPickerChange = (e) => { pickerIndex.value = e.detail.value }
const onDateChange = (e) => { date.value = e.detail.value }
const onTimeChange = (e) => { time.value = e.detail.value }
const onRegionChange = (e) => { region.value = e.detail.value }
</script>

<style>
.picker { padding: 30rpx; border-bottom: 1rpx solid #eee; }
</style>
```

### 4. radio / checkbox / switch / slider

```vue
<template>

    <!-- 单选 -->

<script setup>

  { value: '2', label: '女', checked: false }

const onCheckboxChange = (e) => console.log('选中：', e.detail.value)
const onSwitchChange = (e) => console.log('开关：', e.detail.value)
```

## 四、媒体组件

### 1. image - 图片

```vue
<template>
  <view>
    <!-- 基础用法 -->
    <image src="/static/logo.png" class="logo" />
    
    <!-- 网络图片 + 填充模式 -->
    <image 
      src="https://example.com/pic.jpg"
      mode="aspectFill"
      class="pic"
      @load="onImageLoad"
      @error="onImageError"
      lazy-load
    />
    
    <!-- 图片预览（点击放大） -->
    <image 
      v-for="(url, index) in images" 
      :key="index"
      :src="url"
      @click="previewImage(index)"
      class="thumb"
    />
  </view>
</template>

<script setup>
const images = [
  'https://example.com/1.jpg',
  'https://example.com/2.jpg',
  'https://example.com/3.jpg'
]

const previewImage = (current) => {
  uni.previewImage({
    current,
    urls: images
  })
}

const onImageLoad = () => console.log('图片加载成功')
const onImageError = () => console.log('图片加载失败')
</script>

<style>
.logo { width: 200rpx; height: 200rpx; }
.pic { width: 100%; height: 400rpx; }
.thumb { width: 200rpx; height: 200rpx; margin: 10rpx; }
</style>
```

**mode 填充模式**：
- `scaleToFill` - 不保持比例，拉伸填满（默认，可能变形）
- `aspectFit` - 保持比例，完整显示，可能有空白
- `aspectFill` - 保持比例，填满容器，可能裁剪（最常用）
- `widthFix` - 宽度固定，高度自动变化

## 五、导航与页面跳转

### 1. navigator - 页面链接

```vue
<template>
  <view>
    <!-- 跳转到普通页面 -->
    <navigator url="/pages/detail/detail?id=123">去详情页</navigator>
    
    <!-- 跳转到 tabBar 页面 -->
    <navigator url="/pages/index/index" open-type="switchTab">去首页</navigator>
    
    <!-- 返回上一页 -->
    <navigator open-type="navigateBack">返回</navigator>
  </view>
</template>
```

### 2. JS方式跳转（更常用）

```javascript
// 保留当前页面，跳转到新页面（可以返回）
uni.navigateTo({
  url: '/pages/detail/detail?id=123&name=张三'
})

// 关闭当前页面，跳转到新页面（不能返回）
uni.redirectTo({
  url: '/pages/login/login'
})

// 跳转到 tabBar 页面（会关闭其他所有非 tabBar 页面）
uni.switchTab({
  url: '/pages/index/index'
})

// 关闭所有页面，打开新页面
uni.reLaunch({
  url: '/pages/index/index'
})

// 返回上一页
uni.navigateBack({
  delta: 1  // 返回几层，默认1
})

// 获取页面参数（在 onLoad 中）
onLoad((options) => {
  console.log(options.id)    // '123'
  console.log(options.name)  // '张三'
})
```

## 六、常用API速查

### 交互反馈

```javascript
// 显示加载中
uni.showLoading({ title: '加载中...', mask: true })
uni.hideLoading()

// 显示提示
uni.showToast({ title: '成功', icon: 'success', duration: 2000 })
// icon 可选：success / error / loading / none

// 显示模态框
uni.showModal({
  title: '提示',
  content: '确定要删除吗？',
  confirmColor: '#dd524d',
  success: (res) => {
    if (res.confirm) {
      console.log('用户点击确定')
    } else if (res.cancel) {
      console.log('用户点击取消')
    }
  }
})

// 显示操作菜单
uni.showActionSheet({
  itemList: ['拍照', '从相册选择'],
  success: (res) => {
    console.log('选中了第' + (res.tapIndex + 1) + '个')
  }
})
```

### 存储

```javascript
// 本地存储（同步）
uni.setStorageSync('token', 'abc123')
const token = uni.getStorageSync('token')
uni.removeStorageSync('token')

// 本地存储（异步）
uni.setStorage({
  key: 'userInfo',
  data: { name: '张三', age: 25 },
  success: () => console.log('保存成功')
})
```
