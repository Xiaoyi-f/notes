# 01 - 环境搭建

## 一、需要安装的工具

### 1. 开发工具：HBuilderX（官方推荐）

```
下载地址：https://www.dcloud.io/hbuilderx.html
选择：App开发版（含uni-app插件）
```

安装步骤：
1. 下载对应系统版本（Windows/Mac）
2. 解压到任意目录（绿色软件，无需安装）
3. 打开 HBuilderX.exe
4. 安装插件：工具 → 插件安装 → 安装 scss/sass 编译、uni-app(App) 等

### 2. 微信开发者工具（开发微信小程序必须）

```
下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
```

安装后需要在 HBuilderX 中配置路径：
```
工具 → 设置 → 运行设置 → 微信开发者工具路径
```

### 3. Node.js（使用CLI方式时需要）

```bash
# 下载安装：https://nodejs.org/ （选 LTS 版本）
# 验证安装
node -v    # 应显示版本号，如 v20.x.x
npm -v     # 应显示版本号
```

## 二、创建第一个 UniApp 项目

### 方式一：HBuilderX 可视化创建（推荐新手）

```
文件 → 新建 → 项目 → 选择 "uni-app" 模板
→ 填写项目名称（如 first-app）
→ 选择 Vue版本（建议 Vue3）
→ 勾选 TypeScript（建议）
→ 点击创建
```

### 方式二：命令行创建（适合习惯CLI的开发者）

```bash
# 全局安装脚手架
npm install -g @dcloudio/uni-app-cli

# 创建项目（使用uni-app官方模板）
npx degit dcloudio/uni-preset-vue#vite-ts my-project

# 进入项目目录
cd my-project

# 安装依赖
npm install

# 运行到浏览器（H5）
npm run dev:h5

# 运行到微信小程序
npm run dev:mp-weixin
```

## 三、项目结构详解

```
my-project/                          # 项目根目录
├── .husky/                          # git钩子（可选）
├── node_modules/                    # 依赖包（不用管）
├── src/                             # 源代码目录（主要工作区）
│   ├── components/                  # 自定义组件
│   │   └── MyButton.vue             # 示例组件
│   ├── pages/                       # 页面目录（每个文件夹是一个页面）
│   │   ├── index/                   # 首页
│   │   │   └── index.vue            # 首页代码
│   │   └── about/                   # 关于页
│   │       └── about.vue
│   ├── static/                      # 静态资源（图片、字体等）
│   │   └── logo.png
│   ├── stores/                      # Pinia状态管理（Vue3）
│   │   └── user.js                  # 用户状态
│   ├── utils/                       # 工具函数
│   │   └── request.js               # 封装网络请求
│   ├── App.vue                      # 应用入口（全局样式、生命周期）
│   ├── main.js                      # 应用入口JS（注册插件等）
│   ├── manifest.json                # 应用配置（AppID、权限等）
│   ├── pages.json                   # 页面路由配置
│   └── uni.scss                     # 全局SCSS变量
├── index.html                       # H5入口
├── package.json                     # 项目依赖
├── vite.config.js                   # Vite配置
└── tsconfig.json                    # TypeScript配置
```

## 四、核心配置文件详解

### 1. pages.json - 页面路由配置

```json
{
  "pages": [
    {
      "path": "pages/index/index",
      "style": {
        "navigationBarTitleText": "首页"
      }
    },
    {
      "path": "pages/about/about",
      "style": {
        "navigationBarTitleText": "关于我们"
      }
    }
  ],
  "globalStyle": {
    "navigationBarTextStyle": "black",
    "navigationBarBackgroundColor": "#F8F8F8",
    "backgroundColor": "#F8F8F8"
  },
  "tabBar": {
    "list": [
      { "pagePath": "pages/index/index", "text": "首页" },
      { "pagePath": "pages/about/about", "text": "我的" }
    ]
  }
}
```

**重要**：每新建一个页面，都要在 `pages.json` 的 `pages` 数组中注册！

### 2. manifest.json - 应用配置

```json
{
  "name": "我的应用",
  "appid": "__UNI__XXXXXXX",
  "description": "这是一个uni-app应用",
  "versionName": "1.0.0",
  "versionCode": "100",
  "app-plus": {
    "splashscreen": {
      "alwaysShowBeforeRender": true
    }
  },
  "mp-weixin": {
    "appid": "wx你的小程序appid",
    "setting": {
      "urlCheck": false
    }
  },
  "h5": {
    "title": "H5应用"
  }
}
```

### 3. App.vue - 应用入口

```vue
<script setup>
import { onLaunch, onShow, onHide } from '@dcloudio/uni-app'

// 应用启动时执行（只执行一次）
onLaunch(() => {
  console.log('App Launch')
})

// 应用显示时执行（从后台回到前台）
onShow(() => {
  console.log('App Show')
})

// 应用隐藏时执行（从前台到后台）
onHide(() => {
  console.log('App Hide')
})
</script>

<style>
/* 全局公共样式 */
page {
  font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
}
</style>
```

## 五、运行项目

### HBuilderX 中运行

```
点击工具栏的运行按钮 ▶
├── 运行到浏览器 → Chrome/Edge/Safari/Firefox
├── 运行到手机或模拟器 → 需连接手机开启USB调试
├── 运行到小程序模拟器 → 微信开发者工具
└── 运行到终端 → 命令行输出
```

### 常用运行命令（CLI方式）

```bash
# H5
npm run dev:h5

# 微信小程序
npm run dev:mp-weixin

# 支付宝小程序
npm run dev:mp-alipay

# App（需要基座运行）
npm run dev:app

# Android
npm run dev:app-android

# iOS
npm run dev:app-ios
```

## 六、真机调试（Android）

1. 手机开启 **开发者选项** → **USB调试**
2. 用数据线连接电脑
3. HBuilderX 中点击 "运行" → "运行到手机或模拟器"
4. 选择已连接的设备
5. 首次需要安装 "uni-app 基座"（自动安装）

## 七、第一个页面代码示例

```vue
<!-- pages/index/index.vue -->
<template>
  <view class="container">
    <text class="title">Hello UniApp!</text>
    <button @click="sayHello">点击我</button>
  </view>
</template>

<script setup>
import { ref } from 'vue'

const count = ref(0)

const sayHello = () => {
  count.value++
  uni.showToast({
    title: `你点击了${count.value}次`,
    icon: 'none'
  })
}
</script>

<style scoped>
.container {
  padding: 40rpx;
  text-align: center;
}
.title {
  font-size: 48rpx;
  color: #333;
  margin-bottom: 40rpx;
}
</style>
```

**注意**：UniApp 中使用 `rpx` 作为尺寸单位，它会自动适配不同屏幕宽度。`750rpx = 屏幕宽度`。

## 八、常见问题

| 问题 | 解决方法 |
|------|---------|
| 微信小程序提示 "未绑定AppID" | 在 manifest.json → mp-weixin → appid 填入你的小程序AppID |
| 真机运行找不到设备 | 检查USB调试是否开启，换条数据线试试 |
| HBuilderX 启动报错 | 以管理员身份运行，或检查杀毒软件拦截 |
| npm install 报错 | 使用淘宝镜像：`npm config set registry https://registry.npmmirror.com` |
