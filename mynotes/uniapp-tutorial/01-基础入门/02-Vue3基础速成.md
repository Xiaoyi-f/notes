# 02 - Vue3 基础速成（UniApp专用版）

> 如果你已经会 Vue3，可以跳过本章。本章针对零基础小白，只讲UniApp开发中最常用的Vue3特性。

## 一、模板语法

### 1. 文本插值

```vue
<template>
  <view>
    <!-- {{ }} 里面放变量或表达式 -->
    <text>{{ message }}</text>
    <text>{{ 1 + 1 }}</text>        <!-- 显示 2 -->
    <text>{{ message.toUpperCase() }}</text>
  </view>
</template>

<script setup>
const message = 'Hello UniApp'
</script>
```

### 2. 绑定属性 v-bind（简写 :）

```vue
<template>
  <view>
    <!-- 完整写法 -->
    <image v-bind:src="imgUrl"></image>
    
    <!-- 简写（推荐） -->
    <image :src="imgUrl"></image>
    
    <!-- 动态class -->
    <view :class="{ active: isActive, 'text-danger': hasError }">
      动态样式
    </view>
    
    <!-- 动态style -->
    <view :style="{ color: textColor, fontSize: size + 'rpx' }">
      内联样式
    </view>
  </view>
</template>

<script setup>
const imgUrl = '/static/logo.png'
const isActive = true
const hasError = false
const textColor = '#ff0000'
const size = 32
</script>
```

### 3. 事件绑定 v-on（简写 @）

```vue
<template>
  <view>
    <!-- 点击事件 -->
    <button @click="handleClick">点击</button>
    
    <!-- 传递参数 -->
    <button @click="handleClick('参数')">带参数</button>
    
    <!-- 阻止冒泡 -->
    <view @click.stop="innerClick">
      <button @click="buttonClick">不会触发父元素</button>
    </view>
    
    <!-- 阻止默认行为 -->
    <form @submit.prevent="onSubmit">
      <button form-type="submit">提交</button>
    </form>
  </view>
</template>

<script setup>
const handleClick = (msg = '') => {
  uni.showToast({ title: `点击了${msg}` })
}

const innerClick = () => console.log('inner')
const buttonClick = () => console.log('button')
const onSubmit = () => console.log('提交表单')
</script>
```

### 4. 条件渲染

```vue
<template>
  <view>
    <!-- v-if: 条件为false时不渲染（移除DOM） -->
    <view v-if="isLogin">欢迎回来，用户</view>
    <view v-else>请先登录</view>
    
    <!-- v-show: 条件为false时隐藏（display:none） -->
    <view v-show="isLoading">加载中...</view>
    
    <!-- v-if / v-else-if / v-else -->
    <view v-if="score >= 90">优秀</view>
    <view v-else-if="score >= 60">及格</view>
    <view v-else>不及格</view>
  </view>
</template>

<script setup>
const isLogin = false
const isLoading = true
const score = 85
</script>
```

### 5. 列表渲染 v-for

```vue
<template>
  <view>
    <!-- 遍历数组 -->
    <view 
      v-for="(item, index) in list" 
      :key="item.id"
      class="item"
    >
      {{ index + 1 }}. {{ item.name }} - ¥{{ item.price }}
    </view>
    
    <!-- 遍历对象 -->
    <view v-for="(value, key) in userInfo" :key="key">
      {{ key }}: {{ value }}
    </view>
  </view>
</template>

<script setup>
const list = [
  { id: 1, name: '苹果', price: 5 },
  { id: 2, name: '香蕉', price: 3 },
  { id: 3, name: '橙子', price: 4 }
]

const userInfo = {
  name: '张三',
  age: 25,
  city: '北京'
}
</script>
```

**重要**：`v-for` 必须写 `:key`，且 key 要唯一！

## 二、响应式数据 ref 和 reactive

### 1. ref - 用于基本类型和单值

```vue
<script setup>
import { ref } from 'vue'

// 定义响应式数据
const count = ref(0)          // 数字
const name = ref('张三')       // 字符串
const isShow = ref(true)      // 布尔值

// 在 script 中读取/修改要用 .value
const add = () => {
  count.value++
  console.log(count.value)
}

// 在 template 中直接用，不用 .value
</script>

<template>
  <view>
    <text>{{ count }}</text>
    <button @click="add">+1</button>
  </view>
</template>
```

### 2. reactive - 用于对象

```vue
<script setup>
import { reactive } from 'vue'

// 定义响应式对象
const user = reactive({
  name: '张三',
  age: 25,
  hobbies: ['篮球', '音乐']
})

// 修改属性（不用 .value）
const addAge = () => {
  user.age++
  user.hobbies.push('游泳')
}
</script>
```

### 3. 选择建议

| 场景 | 使用 |
|------|------|
| 数字、字符串、布尔 | `ref` |
| 对象、数组 | `reactive` 或 `ref` |
| 需要整体替换对象 | `ref`（reactive不能整体替换） |

## 三、计算属性 computed

```vue
<script setup>
import { ref, computed } from 'vue'

const firstName = ref('张')
const lastName = ref('三')

// 计算全名（有缓存，依赖不变不会重新计算）
const fullName = computed(() => {
  return firstName.value + lastName.value
})

// 可读写的计算属性
const fullName2 = computed({
  get: () => firstName.value + lastName.value,
  set: (val) => {
    firstName.value = val[0]
    lastName.value = val.slice(1)
  }
})

const cart = ref([
  { name: '苹果', price: 5, num: 2 },
  { name: '香蕉', price: 3, num: 3 }
])

// 计算总价
const total = computed(() => {
  return cart.value.reduce((sum, item) => sum + item.price * item.num, 0)
})
</script>

<template>
  <view>
    <text>姓名：{{ fullName }}</text>
    <text>购物车总价：¥{{ total }}</text>
  </view>
</template>
```

## 四、侦听器 watch

```vue
<script setup>
import { ref, watch } from 'vue'

const searchKey = ref('')
const user = reactive({ name: '张三', age: 25 })

// 监听 ref
watch(searchKey, (newVal, oldVal) => {
  console.log('搜索词从', oldVal, '变成', newVal)
  // 可以在这里调用搜索接口
})

// 监听 reactive 对象的某个属性
watch(() => user.age, (newVal) => {
  console.log('年龄变成', newVal)
})

// 监听整个对象（深度监听）
watch(user, (newVal) => {
  console.log('user变化了', newVal)
}, { deep: true })

// 立即执行一次
watch(searchKey, (newVal) => {
  console.log('当前值：', newVal)
}, { immediate: true })
</script>
```

## 五、生命周期（UniApp页面版）

```vue
<script setup>
import { 
  onLoad,      // 页面加载（类似Vue的onMounted）
  onShow,      // 页面显示
  onHide,      // 页面隐藏
  onUnload,    // 页面卸载
  onPullDownRefresh,  // 用户下拉刷新
  onReachBottom,      // 页面上拉触底
  onShareAppMessage   // 用户点击分享
} from '@dcloudio/uni-app'

// 接收页面参数
onLoad((options) => {
  console.log('页面参数：', options)
  // 如 url?id=123 → options.id === '123'
})

onShow(() => {
  console.log('页面显示了')
})

onHide(() => {
  console.log('页面隐藏了')
})

// 下拉刷新
onPullDownRefresh(() => {
  console.log('用户下拉了')
  // 刷新数据...
  uni.stopPullDownRefresh()  // 停止刷新动画
})

// 触底加载更多
onReachBottom(() => {
  console.log('滚动到底部了')
  // 加载下一页数据...
})
</script>
```

**页面生命周期对比**：

| Vue3 | UniApp页面 |
|------|-----------|
| onMounted | onLoad / onShow |
| onUnmounted | onUnload |
| - | onPullDownRefresh（特有） |
| - | onReachBottom（特有） |

## 六、组件基础

### 1. 创建子组件

```vue
<!-- components/MyButton.vue -->
<template>
  <button 
    class="my-btn" 
    :class="type"
    @click="onClick"
  >
    {{ text }}
  </button>
</template>

<script setup>
// 定义 props（父组件传入的数据）
const props = defineProps({
  text: { type: String, default: '按钮' },
  type: { type: String, default: 'primary' }  // primary / warning / danger
})

// 定义 emits（向父组件发送事件）
const emit = defineEmits(['click'])

const onClick = () => {
  emit('click')
}
</script>

<style scoped>
.my-btn {
  padding: 20rpx 40rpx;
  border-radius: 8rpx;
  border: none;
}
.primary { background: #007aff; color: white; }
.warning { background: #f0ad4e; color: white; }
.danger { background: #dd524d; color: white; }
</style>
```

### 2. 使用子组件

```vue
<!-- pages/index/index.vue -->
<template>
  <view>
    <!-- 引入并使用 -->
    <MyButton text="确认" type="primary" @click="onConfirm" />
    <MyButton text="删除" type="danger" @click="onDelete" />
    
    <!-- 使用 v-model（双向绑定） -->
    <input v-model="inputValue" placeholder="请输入" />
    <text>你输入了：{{ inputValue }}</text>
  </view>
</template>

<script setup>
import { ref } from 'vue'
import MyButton from '@/components/MyButton.vue'

const inputValue = ref('')

const onConfirm = () => {
  uni.showToast({ title: '确认' })
}

const onDelete = () => {
  uni.showModal({
    title: '确认删除？',
    success: (res) => {
      if (res.confirm) {
        uni.showToast({ title: '已删除' })
      }
    }
  })
}
</script>
```
