# 03 - H5 打包与部署到云服务器

---

## 一、打包

```bash
# CLI方式
npm run build:h5

# 输出目录：dist/build/h5
```

### HBuilderX方式：

```
发行 → 网站-PC Web或手机H5 → 填写网站标题和域名 → 发行
```

---

## 二、部署到云服务器

### 方式一：直接上传静态文件

```bash
# 使用 scp 上传到服务器（需要ssh密钥或密码）
scp -r dist/build/h5/* root@你的服务器IP:/var/www/html/

# 或者用 FTP 工具（如 FileZilla）上传
```

### 方式二：使用宝塔面板（推荐新手）

```
1. 登录宝塔面板
2. 网站 → 添加站点 → 填写域名
3. 进入站点目录 /www/wwwroot/你的域名
4. 上传打包后的文件（删除默认文件）
5. 设置运行目录为根目录
6. 配置SSL证书（HTTPS）
```

### 方式三：使用 Nginx 部署

```nginx
# /etc/nginx/conf.d/yoursite.conf
server {
    listen 80;
    server_name yoursite.com;
    
    # 强制HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name yoursite.com;
    
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    
    root /var/www/html;
    index index.html;
    
    # 处理前端路由（Vue Router history模式）
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
    
    # API代理（解决跨域）
    location /api/ {
        proxy_pass http://localhost:8080/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 三、跨域配置

H5部署后，前端调用后端API会遇到跨域问题。

### 后端解决（推荐）：

```java
// Spring Boot 配置
@Configuration
public class CorsConfig implements WebMvcConfigurer {
    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/**")
            .allowedOrigins("https://yoursite.com", "https://app.yoursite.com")
            .allowedMethods("GET", "POST", "PUT", "DELETE", "OPTIONS")
            .allowedHeaders("*")
            .allowCredentials(true)
            .maxAge(3600);
    }
}
```

### 前端代理（开发环境）：

```javascript
// vite.config.js
export default {
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:8080',
        changeOrigin: true
      }
    }
  }
}
```
