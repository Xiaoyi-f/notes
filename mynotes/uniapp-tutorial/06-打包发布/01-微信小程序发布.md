# 01 - 微信小程序打包与发布

---

## 一、准备工作

1. **注册微信小程序账号**：https://mp.weixin.qq.com
2. **获取 AppID**：登录后台 → 开发 → 开发设置 → AppID
3. **添加开发者**：成员管理 → 添加项目成员

---

## 二、配置 AppID

```json
// manifest.json
{
  "mp-weixin": {
    "appid": "wx你的小程序AppID",
    "setting": {
      "urlCheck": false,
      "es6": true,
      "postcss": true,
      "minified": true
    }
  }
}
```

---

## 三、打包上传

### HBuilderX 方式：

```
1. 点击菜单：发行 → 小程序-微信
2. 填写小程序名称和AppID
3. 点击 "发行"
4. 会自动打开微信开发者工具
5. 在微信开发者工具中点击 "上传"
6. 填写版本号和项目备注
7. 上传成功
```

### CLI 方式：

```bash
# 打包
npm run build:mp-weixin

# 然后用微信开发者工具打开 dist/build/mp-weixin 目录
# 点击上传
```

---

## 四、提交审核

```
1. 登录微信小程序后台：https://mp.weixin.qq.com
2. 管理 → 版本管理 → 开发版本
3. 找到刚上传的版本，点击 "提交审核"
4. 填写功能页面（至少填首页）
5. 提交审核，等待1-3个工作日
```

---

## 五、常见问题

| 问题 | 解决 |
|------|------|
| 包体积超过2MB | 图片放CDN，使用分包加载 |
| 提示 "pages未配置" | 检查 pages.json 的 pages 数组 |
| 请求接口失败 | 检查小程序后台 → 开发设置 → 服务器域名是否配置 |
| 审核被拒 | 检查是否有违规内容，用户协议和隐私政策是否完整 |

---

## 六、服务器域名配置

```
微信小程序后台 → 开发 → 开发设置 → 服务器域名

request合法域名：   https://api.yoursite.com
socket合法域名：    wss://ws.yoursite.com
uploadFile合法域名：https://oss.yoursite.com
downloadFile合法域名：https://cdn.yoursite.com
```

**注意**：域名必须备案，且只支持 HTTPS！
