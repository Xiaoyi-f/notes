21.java注释 /* 内容 */    // 内容
22.作用域会决定变量的可见性和生命周期
23.java中对象的生命周期和基本数据类型的不同
    new创建的对象，即使是离开对应作用域，对应的标识符不再能使用，但是底层的内存还是没有清空，然而new创建的对象会被GC监控消除
24.字段分为实例字段和类字段，对应python的实例变量和类变量，具体的使用范围可以使用关键词进行限定
访问控制修饰符:
    public 公共的，可以被任何其他类访问
    protected 受保护的，对于同一包内所有类和无论何处包的任何子类可见
    default 默认全选，只对于同一个包内类可见
    private 私有，只能在定义的类中可见，其他任何地方不可见
非访问控制修饰符:
    static 类和实例均可直接调用
    final 使不可变

33.java --list-modules 列出所有可使用模块
    @标识正在使用的jdk版本
34."委托"是一种设计思想——把任务交给另一个对象去执行
35.把子类对象当作父类类型来用即向上转型，向上转型只能够使用子类和父类共同拥有的方法或者属性，但是实际使用的是子类的方法或者属性
36.Python不需要显式构建，是因为它的“构建”步骤被解释器和包管理工具隐藏了；而Java需要构建，是因为从源代码到可运行程序之间，多了一个编译和打包的环节
37.用户请求服务都是会带有对应的ip的，服务的后端可以实现检测某些情况进行ip封锁
38.如果使用+的拼接功能，若周围是字符串则会进行隐式字符串转换，且拼接运算总是在单目运算完全之后
39.基本输出方式System.out.println() System.out.printf()
    自动换行输出只能使用+拼接
    格式化输出可以使用如下占位符:
        %d %s %f(无论float或double) %c %b(boolean) %n(跨平台换行，\n是Unicode编码) %X %O %E %% （m.n）
40.java字符串编码默认使用UTF-16，java17以即之前版本默认编码依赖操作系统，之后版本默认UTF-8
41.基本条件控制:
    for for ( : )
    while
    if else if else
    switch () case : break; default:
42.java中除了构造方法、static方法、final方法、private方法，其他实例方法默认都是后期绑定的
43.private方法默认就是final特性的
44.具有final特性的方法不能在子类中进行重写，但是重载是没有问题的
45.静态字段在内存中只有一份，被整个应用程序的所有线程共享，静态方法在类加载时就存在，此时可能还没有创建任何对象，字段通常是private的
46.为了确保子类所有数据完善，基类的构造器会在子类的构造过程中被调用，若没有在子类中显示调用父类构造器，那么编译器会自动调用，若没有写构造器则编译器自动合成无参构造器
47.构造器名字需要和类名字一样，支持重载并且无返回类型，this()用于调用本类的其他构造器，super()用于调用父类的构造器
48.为了避免循环引用问题，大多java编译器的GC并没有使用引用计数功能，而是使用更加强大的可达性分析算法
49.Java的数组一定会被初始化，若没有手动初始化默认会给null，并且无法访问数组边界之外的元素
50.窄化转型就是说，将能容纳更多信息的数据类型转换成无法容纳那么多信息的数据类型
51.var会自动推断类型，推荐在局部变量中使用
52.final类禁止继承，它的所有方法都是隐式final的，因为无法重写它们
53.向上转型：子类对象转为父类引用，自动发生，绝对安全；向下转型：父类引用转回子类引用，必须强制进行，且存在风险
54.接口可以实现多个，类一般只能继承一个，可以通过继承扩展接口
55.sealed只允许指定的几个孩子，类前面加 sealed，并写明允许哪几个子类继承，示例: sealed class Animal permits Dog, Cat {}
56.non-sealed —— 重新“打开”继承，当你在 sealed 的子类上写 non-sealed，意思是：从这个子类往下，又可以随意继承
    示例:
        sealed class Animal permits Dog {}
        non-sealed class Dog extends Animal {}
        class AnyDog extends Dog {}   // ✅ 允许
57.接口中的任何类都会自动成为public和static的。因为类是static的，所以被嵌套的类只是放在了这个接口的命名空间内
