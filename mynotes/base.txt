46.为了确保子类所有数据完善，基类的构造器会在子类的构造过程中被调用，若没有在子类中显示调用父类构造器，那么编译器会自动调用，若没有写构造器则编译器自动合成无参构造器
47.构造器名字需要和类名字一样，支持重载并且无返回类型，this()用于调用本类的其他构造器，super()用于调用父类的构造器
48.为了避免循环引用问题，大多java编译器的GC并没有使用引用计数功能，而是使用更加强大的可达性分析算法
49.Java的数组一定会被初始化，若没有手动初始化默认会给null，并且无法访问数组边界之外的元素
50.窄化转型就是说，将能容纳更多信息的数据类型转换成无法容纳那么多信息的数据类型

53.向上转型：子类对象转为父类引用，自动发生，绝对安全；向下转型：父类引用转回子类引用，必须强制进行，且存在风险
54.接口可以实现多个，类一般只能继承一个，可以通过继承扩展接口
55.sealed只允许指定的几个孩子，类前面加 sealed，并写明允许哪几个子类继承，示例: sealed class Animal permits Dog, Cat {}
56.non-sealed —— 重新“打开”继承，当你在 sealed 的子类上写 non-sealed，意思是：从这个子类往下，又可以随意继承
    示例:
        sealed class Animal permits Dog {}
        non-sealed class Dog extends Animal {}
        class AnyDog extends Dog {}   // ✅ 允许
57.接口中的任何类都会自动成为public和static的。因为类是static的，所以被嵌套的类只是放在了这个接口的命名空间内
58.静态导入
    只能 import static 那些用 static 修饰的方法或变量，如果你试图导入一个普通方法（非静态方法），编译器会直接报错
    不要滥用通配符 *：
        虽然 import static onjava.Range.*; 很方便，但如果两个不同的类里都有同名的静态方法（比如 Math.max 和 MyUtils.max），你同时用 * 导入它们，编译器就会“懵圈”（报错：引用不明确），因为它不知道该用哪一个
