### 1. Java 基础

```java
/**
 * Java 基础高频题
 */

// 1. equals 和 hashCode
/*
- 如果 equals 返回 true，hashCode 必须相等
- 重写 equals 时必须重写 hashCode
- 如果只重写 equals 不重写 hashCode，会导致 HashMap、HashSet 的问题
*/

class User {
    private Long id;
    private String username;

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        User user = (User) o;
        return Objects.equals(id, user.id);
    }

    @Override
    public int hashCode() {
        return Objects.hash(id);  // 使用稳定的字段
    }
}

// 2. String 不可变性
/*
String 是不可变的，原因：
1. 安全性：防止敏感信息被修改
2. 线程安全：多线程环境下无需同步
3. 缓存：hashCode 可以缓存，提高 HashMap 性能
4. String 常量池：共享字符串，减少内存占用
*/

// 3. 接口与抽象类
/*
相同点：
- 都不能直接实例化
- 都可以有抽象方法
- 都可以有默认实现（接口的 default 方法）

不同点：
- 接口：多重继承，只能有抽象方法和常量
- 抽象类：单继承，可以有构造器、成员变量、具体方法
*/

// 4. 集合框架
/*
List：有序，可重复
- ArrayList：数组实现，查询快 O(1)，插入删除慢 O(n)
- LinkedList：链表实现，查询慢 O(n)，插入删除快 O(1)

Set：无序，不可重复
- HashSet：基于 HashMap，O(1)
- TreeSet：基于 TreeMap，有序，O(log n)

Map：键值对
- HashMap：无序，非线程安全，O(1)
- TreeMap：有序，O(log n)
- ConcurrentHashMap：线程安全，分段锁
*/
```

### 2. 并发编程

```java
/**
 * 并发编程高频题
 */

// 1. 线程池参数
/*
ThreadPoolExecutor 参数：
- corePoolSize：核心线程数，常驻线程
- maximumPoolSize：最大线程数
- keepAliveTime：空闲线程存活时间
- workQueue：任务队列
- threadFactory：线程工厂
- handler：拒绝策略

拒绝策略：
- AbortPolicy：抛出异常（默认）
- CallerRunsPolicy：调用者线程执行
- DiscardPolicy：丢弃任务
- DiscardOldestPolicy：丢弃最旧的任务
*/

ThreadPoolExecutor executor = new ThreadPoolExecutor(
    10,                              // 核心线程数
    20,                              // 最大线程数
    60L, TimeUnit.SECONDS,          // 存活时间
    new LinkedBlockingQueue<>(1000), // 任务队列
    Executors.defaultThreadFactory(),  // 线程工厂
    new ThreadPoolExecutor.CallerRunsPolicy()  // 拒绝策略
);

// 2. volatile
/*
作用：
1. 保证可见性：一个线程修改，其他线程立即可见
2. 禁止指令重排序

不保证原子性：
volatile int i = 0;
i++;  // 不是原子操作，需要加锁

使用场景：
1. 状态标记位
2. 单例模式的双重检查
*/

// 3. synchronized
/*
对象锁：锁对象实例
方法锁：锁当前实例
静态锁：锁 Class 对象
*/

// 4. 锁优化
/*
偏向锁：只有一个线程访问，消除同步开销
轻量级锁：多个线程交替访问，自旋
重量级锁：多个线程同时访问，阻塞

锁升级：偏向锁 -> 轻量级锁 -> 重量级锁
锁降级：JVM 不支持（HotSpot 不支持）

锁消除：JVM 检测到不存在竞争，消除锁
锁粗化：将连续的锁操作合并
*/
```

```java
public String generateShortUrl(String longUrl) {
    // 1. 检查缓存
    String shortUrl = redisTemplate.opsForValue().get(longUrl);
    if (shortUrl != null) {
        return shortUrl;
    }

    // 2. 生成唯一 ID
    long id = snowflakeIdGenerator.nextId();

    // 3. Base62 编码
    shortUrl = Base62.encode(id);

    // 4. 存储数据库
    Link link = new Link(id, shortUrl, longUrl);
    linkRepository.save(link);

    // 5. 写入缓存
    redisTemplate.opsForValue().set(longUrl, shortUrl, Duration.ofDays(7));

    return shortUrl;
}
```

**URL 跳转**：
```java
public String redirect(String shortUrl) {
    // 1. 检查缓存
    String longUrl = redisTemplate.opsForValue().get(shortUrl);
    if (longUrl != null) {
        // 更新访问计数
        incrementAccessCount(shortUrl);
        return longUrl;
    }

    // 2. 查询数据库
    Link link = linkRepository.findByShortUrl(shortUrl);
    if (link == null || link.isExpired()) {
        throw new ResourceNotFoundException("链接不存在或已过期");
    }

    longUrl = link.getLongUrl();

    // 3. 写入缓存
    redisTemplate.opsForValue().set(shortUrl, longUrl, Duration.ofDays(7));

    // 4. 更新访问计数
    incrementAccessCount(shortUrl);

    return longUrl;
}
```

### 2. 谈判策略

```java
/**
 * Offer 谈判策略
 */

// 1. 谈研市场
/*
- 了解市场行情
- 询问同学、同事、猎头
- 查看薪资网站（Boss直聘、拉勾网）
- 了解目标公司的薪资水平
*/

// 2. 谈判准备
/*
- 准备你的价值：
  - 技术能力
  - 项目经验
  - 开源贡献
  - 竞争 Offer
- 准备你的期望：
  - 最低薪资
  - 理想薪资
  - 其他福利
*/

// 3. 谈判技巧
/*
- 先感谢，再表达期望
- 提供具体理由（技术、项目、市场）
- 不要急于接受或拒绝
- 可以要求时间考虑
- 保持礼貌和专业
*/

// 4. 谈判话术
/*
HR: 你的期望薪资是多少？
回答：基于我的技术经验和项目成果，以及市场行情，我期望的年薪是 XX-XX 万。

HR: 我们只能给到 XX 万。
回答：谢谢 offer。考虑到我在 XX 方面的经验，以及带来的价值，能否再考虑一下？

HR: 这是我们的最终 offer。
回答：谢谢 offer，我需要时间考虑。我会在 X 天内给您答复。
*/
```

## 七、常见问题及回答

```java
/**
 * 常见面试问题及回答
 */

// 1. 自我介绍
/*
回答：
您好，我叫张三，5 年后端开发经验。我主要专注于 Java 全栈开发和分布式系统设计。

在上一家公司，我负责电商平台的性能优化，将系统吞吐量从 1k QPS 提升至 10k QPS，响应时间从 200ms 降至 50ms。

我热爱开源，在 GitHub 上有 3 个项目共 1k+ stars。我也热衷于技术分享，在掘金上发表了 20+ 篇文章，累计阅读 50w+。

我对贵公司的业务和技术非常感兴趣，希望能够加入团队，一起创造更好的产品。
*/

// 2. 你最大的缺点
/*
回答：
我有时候会过于追求技术完美，导致在细节上花费较多时间。不过我现在学会了更好地平衡完美和进度，会根据项目情况调整标准。

我也在不断学习时间管理和优先级排序，提高工作效率。
*/

// 3. 你为什么离开上一家公司
/*
回答：
我在上一家公司工作了 3 年，学到了很多，也完成了一些有挑战性的项目。现在我希望能够接触更复杂的技术挑战和更大的业务场景，而贵公司在这方面非常有优势，所以选择了离职。
注意：不要说上一家公司或同事的坏话
*/

// 4. 你有什么问题要问我们
/*
回答：
1. 团队的技术栈是什么？使用哪些技术框架？
2. 团队的工作流程是怎样的？敏捷开发还是瀑布式？
3. 团队的技术挑战有哪些？有什么技术规划？
4. 团队的人员结构是怎样的？资深工程师占多少？
5. 公司的培训机制和晋升通道是怎样的？
6. 如果我加入，前三个月的主要工作是什么？
*/

// 5. 你未来 3-5 年的职业规划
/*
回答：
未来 3-5 年，我希望：
1. 深入学习分布式系统和架构设计
2. 成为技术专家或架构师
3. 带领团队完成有挑战性的项目
4. 在开源社区做出贡献
5. 提升技术影响力，如发表技术文章、参与技术分享

我希望在贵公司能够获得成长和发展的机会，与团队一起成长。
*/
```

## 小结

本节学习了大厂面试准备：

- **面试流程** - 简历筛选、技术面试、系统设计、HR 面试
- **简历优化** - 结构、内容、量化成果、突出重点
- **技术面试** - Java 基础、并发编程、JVM、MySQL、Redis
- **系统设计** - 设计题模板、常见题目、容量估算
- **面试技巧** - 沟通技巧、准备清单、注意事项
- **Offer 谈判** - 薪资构成、谈判策略、话术技巧
- **常见问题** - 自我介绍、缺点、离职原因、反问

## 实践练习

### 编程题
1. 选择一个你做过的项目，用 STAR 法则（情境、任务、行动、结果）准备一份 3 分钟的项目介绍，突出技术难点和个人贡献。
2. 模拟面试：找一位同伴或对着镜子，回答 10 道常见的 Java 基础面试题，录音回放检查表达的清晰度。

### 思考题
1. 面试中如果遇到不会的问题，应该如何应对？直接说"不会"和尝试猜测各有什么风险？
2. 技术面试中，面试官更看重"正确答案"还是"解决问题的思路"？为什么？

### 自测题
1. 面试准备的 STAR 法则是什么？
2. 自我介绍应该包含哪些要素？时间多长合适？
3. 反问环节应该问什么？哪些问题不应问？
