# SQL 学习笔记 - 聚合与分组

## 一、聚合函数

### 1.1 常用聚合函数

| 函数 | 说明 | 适用DISTINCT |
|------|------|--------------|
| `COUNT()` | 统计行数 | ✅ COUNT(DISTINCT 列) |
| `SUM()` | 求和 | ✅ SUM(DISTINCT 列) |
| `AVG()` | 平均值 | ✅ AVG(DISTINCT 列) |
| `MAX()` | 最大值 | ✅ MAX(DISTINCT 列) |
| `MIN()` | 最小值 | ✅ MIN(DISTINCT 列) |

### 1.2 聚合函数示例

```sql
-- COUNT：统计行数
SELECT COUNT(*) FROM employees;              -- 总行数
SELECT COUNT(department) FROM employees;     -- 非NULL值数量
SELECT COUNT(DISTINCT department) FROM employees;  -- 去重后的部门数量

-- SUM：求和
SELECT SUM(salary) FROM employees WHERE department = 'IT';

-- AVG：平均值
SELECT AVG(salary) FROM employees;

-- MAX/MIN：最大最小值
SELECT MAX(salary), MIN(salary) FROM employees;

-- 组合使用
SELECT 
    department,
    COUNT(*) AS emp_count,
    SUM(salary) AS total_salary,
    AVG(salary) AS avg_salary,
    MAX(salary) AS max_salary,
    MIN(salary) AS min_salary
FROM employees
GROUP BY department;
```

---

### 1.3 DISTINCT 与聚合函数

```sql
-- ✅ 正确：DISTINCT 用于列名
SELECT COUNT(DISTINCT department) FROM employees;
SELECT SUM(DISTINCT salary) FROM employees;

-- ❌ 错误：DISTINCT 不能用于计算或表达式
SELECT COUNT(DISTINCT *) FROM employees;
SELECT COUNT(DISTINCT salary * 1.1) FROM employees;

-- 提示：将 DISTINCT 用于 MIN() 和 MAX() 没有意义
SELECT MIN(DISTINCT salary) FROM employees;  -- 等价于 MIN(salary)
SELECT MAX(DISTINCT salary) FROM employees;  -- 等价于 MAX(salary)
```

## 二、GROUP BY 分组

### 2.1 基本语法

```sql
SELECT 分组列, 聚合函数
FROM 表名
WHERE 条件
GROUP BY 分组列
HAVING 过滤条件
ORDER BY 排序;
```

### 2.2 分组示例

```sql
-- 按部门分组，统计员工数
SELECT department, COUNT(*) AS emp_count
FROM employees
GROUP BY department;

-- 按部门和性别分组
SELECT department, gender, COUNT(*) AS emp_count
FROM employees
GROUP BY department, gender;

-- 分组后计算平均工资
SELECT department, AVG(salary) AS avg_salary
FROM employees
GROUP BY department;

-- 多列分组 + 多个聚合函数
SELECT 
    department,
    gender,
    COUNT(*) AS emp_count,
    AVG(salary) AS avg_salary,
    SUM(salary) AS total_salary
FROM employees
GROUP BY department, gender;
```

---

### 2.3 GROUP BY 注意事项

```sql
-- ⚠️ SELECT 中的非聚合列必须在 GROUP BY 中
SELECT department, name, COUNT(*)  -- ❌ 错误：name 不在 GROUP BY 中
FROM employees
GROUP BY department;

-- ✅ 正确
SELECT department, COUNT(*)
FROM employees
GROUP BY department;

-- 或者使用 ANY_VALUE()（MySQL）
SELECT department, ANY_VALUE(name) AS name, COUNT(*)
FROM employees
GROUP BY department;

-- GROUP BY 可以使用表达式
SELECT 
    YEAR(order_date) AS year,
    MONTH(order_date) AS month,
    COUNT(*) AS order_count
FROM orders
GROUP BY YEAR(order_date), MONTH(order_date);
```

## 三、HAVING 过滤分组

### 3.1 WHERE vs HAVING

| 特性 | WHERE | HAVING |
|------|-------|--------|
| **执行时机** | 分组前过滤 | 分组后过滤 |
| **过滤对象** | 原始行 | 分组结果 |
| **聚合函数** | 不能使用 | 可以使用 |
| **执行顺序** | 最先执行 | GROUP BY 之后 |

```
执行顺序：FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
```

---

### 3.2 HAVING 示例

```sql
-- WHERE：分组前过滤
SELECT department, COUNT(*) AS emp_count
FROM employees
WHERE status = 'active'  -- 只统计在职员工
GROUP BY department;

-- HAVING：分组后过滤
SELECT department, COUNT(*) AS emp_count
FROM employees
GROUP BY department
HAVING COUNT(*) > 10;  -- 只显示员工数大于10的部门

-- 组合使用
SELECT department, COUNT(*) AS emp_count, AVG(salary) AS avg_salary
FROM employees
WHERE status = 'active'
GROUP BY department
HAVING COUNT(*) > 5 AND AVG(salary) > 8000;

-- 复杂过滤条件
SELECT 
    department,
    COUNT(*) AS emp_count,
    SUM(salary) AS total_salary
FROM employees
WHERE hire_date >= '2020-01-01'
GROUP BY department
HAVING 
    COUNT(*) >= 5 
    AND SUM(salary) > 50000
    AND AVG(salary) > 8000
ORDER BY total_salary DESC;
```

## 四、GROUP BY 高级用法

### 4.1 GROUP BY WITH ROLLUP（MySQL）

```sql
-- 生成分组小计和总计
SELECT 
    COALESCE(department, '总计') AS department,
    COALESCE(gender, '小计') AS gender,
    COUNT(*) AS emp_count,
    SUM(salary) AS total_salary
FROM employees
GROUP BY department, gender WITH ROLLUP;

-- 结果示例：
-- department | gender | emp_count | total_salary
-- IT          | M      | 10        | 100000
-- IT          | F      | 5         | 50000
-- IT          | 小计   | 15        | 150000
-- HR          | M      | 8         | 80000
-- HR          | F      | 4         | 40000
-- HR          | 小计   | 12        | 120000
-- 总计        | 小计   | 27        | 270000
```

---

### 4.2 GROUPING SETS（PostgreSQL）

```sql
-- 生成多个分组结果
SELECT 
    department,
    gender,
    COUNT(*) AS emp_count
FROM employees
GROUP BY GROUPING SETS (
    (department, gender),  -- 按部门和性别
    (department),          -- 只按部门
    (gender),              -- 只按性别
    ()                     -- 总计
);
```

---

### 4.3 CUBE（PostgreSQL）

```sql
-- 生成所有可能的分组组合
SELECT 
    department,
    gender,
    position,
    COUNT(*) AS emp_count
FROM employees
GROUP BY CUBE (department, gender, position);
-- 相当于所有子组合的 GROUPING SETS
```

## 五、常见分组场景

### 5.1 统计各部门的平均工资

```sql
SELECT 
    d.department_name,
    COUNT(e.id) AS emp_count,
    ROUND(AVG(e.salary), 2) AS avg_salary,
    MIN(e.salary) AS min_salary,
    MAX(e.salary) AS max_salary
FROM departments d
LEFT JOIN employees e ON d.id = e.department_id
GROUP BY d.id, d.department_name
ORDER BY avg_salary DESC;
```

---

### 5.2 统计每个用户的订单数和总金额

```sql
SELECT 
    u.name,
    u.email,
    COUNT(o.id) AS order_count,
    COALESCE(SUM(o.amount), 0) AS total_amount,
    COALESCE(AVG(o.amount), 0) AS avg_amount
FROM users u
LEFT JOIN orders o ON u.id = o.user_id
GROUP BY u.id, u.name, u.email
ORDER BY total_amount DESC;
```

---

### 5.3 统计每天的订单量

```sql
SELECT 
    order_date,
    COUNT(*) AS order_count,
    SUM(amount) AS total_amount
FROM orders
GROUP BY order_date
ORDER BY order_date DESC;
```

---

### 5.4 统计每小时的销售情况

```sql
-- MySQL
SELECT 
    HOUR(created_at) AS hour,
    COUNT(*) AS order_count,
    SUM(amount) AS total_amount
FROM orders
WHERE DATE(created_at) = CURRENT_DATE()
GROUP BY HOUR(created_at)
ORDER BY hour;

-- PostgreSQL
SELECT 
    EXTRACT(HOUR FROM created_at) AS hour,
    COUNT(*) AS order_count,
    SUM(amount) AS total_amount
FROM orders
WHERE DATE(created_at) = CURRENT_DATE
GROUP BY EXTRACT(HOUR FROM created_at)
ORDER BY hour;
```

---

### 5.5 找出每个部门工资最高的员工

```sql
-- 方法一：子查询
SELECT * FROM employees e
WHERE (e.department_id, e.salary) IN (
    SELECT department_id, MAX(salary)
    FROM employees
    GROUP BY department_id
);

-- 方法二：窗口函数
SELECT * FROM (
    SELECT 
        id,
        name,
        department_id,
        salary,
        RANK() OVER (PARTITION BY department_id ORDER BY salary DESC) AS rank
    FROM employees
) ranked
WHERE rank = 1;

-- 方法三：JOIN
SELECT e.* FROM employees e
JOIN (
    SELECT department_id, MAX(salary) AS max_salary
    FROM employees
    GROUP BY department_id
) max_sal ON e.department_id = max_sal.department_id AND e.salary = max_sal.max_salary;
```

---

### 5.6 找出重复数据

```sql
-- 查找重复的邮箱
SELECT email, COUNT(*) AS count
FROM users
GROUP BY email
HAVING COUNT(*) > 1;

-- 删除重复数据（保留最小ID）
DELETE u1 FROM users u1
JOIN (
    SELECT email, MIN(id) AS min_id
    FROM users
    GROUP BY email
    HAVING COUNT(*) > 1
) u2 ON u1.email = u2.email AND u1.id > u2.min_id;
```

## 六、聚合函数高级技巧

### 6.1 字符串聚合

```sql
-- MySQL：GROUP_CONCAT
SELECT 
    department,
    GROUP_CONCAT(name ORDER BY salary DESC SEPARATOR ', ') AS employee_list
FROM employees
GROUP BY department;

-- PostgreSQL：STRING_AGG
SELECT 
    department,
    STRING_AGG(name, ', ' ORDER BY salary DESC) AS employee_list
FROM employees
GROUP BY department;
```

---

### 6.2 条件聚合

```sql
-- 使用 CASE 进行条件聚合
SELECT 
    department,
    COUNT(*) AS total_emp,
    SUM(CASE WHEN gender = 'M' THEN 1 ELSE 0 END) AS male_count,
    SUM(CASE WHEN gender = 'F' THEN 1 ELSE 0 END) AS female_count,
    SUM(CASE WHEN salary > 10000 THEN 1 ELSE 0 END) AS high_salary_count,
    SUM(CASE WHEN salary > 10000 THEN salary ELSE 0 END) AS high_salary_total
FROM employees
GROUP BY department;
```

---

### 6.3 百分位数

```sql
-- MySQL 8.0+
SELECT 
    department,
    PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY salary) AS median_salary,
    PERCENTILE_CONT(0.9) WITHIN GROUP (ORDER BY salary) AS p90_salary
FROM employees
GROUP BY department;

-- PostgreSQL
SELECT 
    department,
    PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY salary) AS median_salary,
    PERCENTILE_CONT(0.9) WITHIN GROUP (ORDER BY salary) AS p90_salary
FROM employees
GROUP BY department;
```

## 七、性能优化

### 7.1 GROUP BY 性能问题

```sql
-- ❌ 慢：没有索引
SELECT department, COUNT(*) 
FROM employees 
GROUP BY department;

-- ✅ 快：添加索引
CREATE INDEX idx_department ON employees(department);

-- ✅ 更快：覆盖索引
CREATE INDEX idx_department_salary ON employees(department, salary);
```

---

### 7.2 避免 SELECT *

```sql
-- ❌ 慢
SELECT * FROM orders 
GROUP BY user_id 
HAVING COUNT(*) > 10;

-- ✅ 快
SELECT user_id, COUNT(*) AS order_count 
FROM orders 
GROUP BY user_id 
HAVING COUNT(*) > 10;
```

---

### 7.3 使用 EXISTS 替代 IN

```sql
-- ❌ 慢：IN 子查询
SELECT * FROM departments d
WHERE d.id IN (SELECT department_id FROM employees GROUP BY department_id HAVING COUNT(*) > 10);

-- ✅ 快：EXISTS
SELECT * FROM departments d
WHERE EXISTS (
    SELECT 1 FROM employees e 
    WHERE e.department_id = d.id 
    GROUP BY e.department_id 
    HAVING COUNT(*) > 10
);
```

## 本节面试考点

| 考点 | 答案要点 |
|------|----------|
| WHERE vs HAVING | WHERE 分组前过滤，HAVING 分组后过滤 |
| GROUP BY 规则 | SELECT 非聚合列必须在 GROUP BY 中 |
| 聚合函数 | COUNT、SUM、AVG、MAX、MIN |
| DISTINCT 用法 | 不能用于 COUNT(*)，可用于 COUNT(DISTINCT 列) |
| 执行顺序 | FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY |
| MySQL 特有 | GROUP_CONCAT 字符串聚合 |
| PostgreSQL 特有 | STRING_AGG、GROUPING SETS、CUBE |
| 条件聚合 | 使用 CASE WHEN |
