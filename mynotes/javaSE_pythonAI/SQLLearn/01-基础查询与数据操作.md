# SQL 学习笔记 - 基础查询与数据操作

## 一、SQL 基础概念

### 1.1 核心概念

| 概念 | 说明 | 示例 |

## 二、SQL 语句基础

### 2.1 SQL 子句执行顺序

```
书写顺序（写代码时的顺序）：
SELECT 
FROM 
WHERE 
GROUP BY
HAVING 
ORDER BY
LIMIT

实际执行顺序（数据库引擎执行顺序）：
FROM       -- 先确定数据来源
WHERE      -- 过滤数据
GROUP BY   -- 分组
HAVING     -- 过滤分组
SELECT     -- 选择列
ORDER BY   -- 排序
LIMIT      -- 限制结果数
```

### 2.2 SELECT 语句

#### 基本语法

```sql
-- 查询单列
SELECT name FROM users;

-- 查询多列
SELECT id, name, email FROM users;

-- 查询所有列（不推荐生产环境使用）
SELECT * FROM users;
```

#### 格式建议

```sql
-- 推荐：多行书写，易读易调试
SELECT 
    id,
    name,
    email,
    created_at
FROM users
WHERE status = 'active';

-- 不推荐：单行堆在一起
SELECT id,name,email,created_at FROM users WHERE status='active';
```

#### 注意事项

| 规则 | 说明 |
|------|------|
| **空格忽略** | 所有空格都被忽略 |
| **逗号分隔** | 多列必须用逗号，最后一列不加 |
| **分号结束** | 每条语句以分号结束 |
| **大小写** | SQL关键字不区分大小写，但表名列名可能区分 |

#### 不使用 * 的原因

```sql
-- ❌ 不推荐：性能差，不灵活
SELECT * FROM users;

-- ✅ 推荐：明确指定需要的列
SELECT id, name, email FROM users;
```

**原因：**
- 检索不需要的列降低性能
- 数据库无法优化查询
- 表结构变化可能导致代码出错
- 传输不必要的数据浪费带宽

## 三、DISTINCT 去重

### 3.1 基本用法

```sql
-- 去重查询单列
SELECT DISTINCT department FROM employees;

-- 去重查询多列（组合去重）
SELECT DISTINCT department, position FROM employees;
```

### 3.2 DISTINCT 特性

| 特性 | 说明 |
|------|------|
| **作用范围** | 作用于所有列，不仅仅是后面那一列 |
| **性能** | 需要排序去重，数据量大时较慢 |
| **与聚合函数** | 不能用于 COUNT(*)，只能用于 COUNT(列名) |

### 3.3 DISTINCT 与聚合函数

```sql
-- ✅ 正确
SELECT COUNT(DISTINCT department) FROM employees;

-- ✅ 正确
SELECT COUNT(DISTINCT department) AS dept_count FROM employees;

-- ❌ 错误
SELECT COUNT(DISTINCT *) FROM employees;

-- ❌ 错误（不能用于计算或表达式）
SELECT COUNT(DISTINCT salary * 1.1) FROM employees;
```

## 四、ORDER BY 排序

### 4.1 基本语法

```sql
-- 单列升序（默认）
SELECT name, salary FROM employees ORDER BY salary;

-- 单列降序
SELECT name, salary FROM employees ORDER BY salary DESC;

-- 多列排序
SELECT name, department, salary 
FROM employees 
ORDER BY department ASC, salary DESC;
```

### 4.2 排序规则

| 规则 | 说明 |
|------|------|
| **数字** | 按数值大小 |
| **字符串** | 按字典序（A-Z） |
| **日期** | 按时间先后 |
| **NULL** | 通常排在最前或最后（取决于数据库） |
| **中文** | 按拼音或编码排序 |

### 4.3 排序注意事项

```sql
-- 位置要求：ORDER BY 必须是最后一条子句
SELECT * FROM users ORDER BY name;  -- ✅

-- 可以使用非检索的列排序
SELECT name FROM employees ORDER BY salary DESC;  -- ✅ 合法

-- 可以使用别名排序
SELECT name, salary AS monthly FROM employees ORDER BY monthly;  -- ✅

-- 可以使用表达式排序
SELECT name, salary FROM employees ORDER BY salary * 12;  -- ✅
```

## 五、WHERE 过滤

### 5.1 WHERE 子句位置

```sql
-- WHERE 必须在 GROUP BY 之前
SELECT department, COUNT(*) 
FROM employees 
WHERE status = 'active'
GROUP BY department;
```

### 5.2 比较操作符

| 操作符 | 说明 | MySQL | PostgreSQL | Neo4j |
|--------|------|-------|------------|---------|
| `=` | 等于 | ✅ | ✅ | ✅（同SQL） |
| `<>` 或 `!=` | 不等于 | ✅ | ✅ | ✅（同SQL） |
| `<` | 小于 | ✅ | ✅ | ✅（同SQL） |
| `<=` | 小于等于 | ✅ | ✅ | ✅（同SQL） |
| `>` | 大于 | ✅ | ✅ | ✅（同SQL） |
| `>=` | 大于等于 | ✅ | ✅ | ✅（同SQL） |
| `IS NULL` | 为空 | ✅ | ✅ | ✅ |
| `STARTS WITH` | 前缀匹配 | ❌ | ❌ | ✅（Cypher特有） |
| `=~` | 正则匹配 | ❌ | ✅ | ✅ |

### 5.3 逻辑操作符

```sql
-- AND：同时满足
SELECT * FROM employees WHERE age >= 25 AND age <= 35;

-- OR：满足任一
SELECT * FROM employees WHERE department = 'IT' OR department = 'HR';

-- NOT：取反
SELECT * FROM employees WHERE NOT (department = 'IT');

-- 优先级：NOT > AND > OR，建议用括号明确
SELECT * FROM employees 
WHERE (department = 'IT' OR department = 'HR') 
AND age >= 25;
```

### 5.4 NULL 值处理

```sql
-- IS NULL：判断为空
SELECT * FROM employees WHERE phone IS NULL;

-- IS NOT NULL：判断不为空
SELECT * FROM employees WHERE phone IS NOT NULL;

-- ⚠️ 注意：不能用 = 或 <> 比较 NULL
SELECT * FROM employees WHERE phone = NULL;   -- ❌ 错误
SELECT * FROM employees WHERE phone IS NULL;  -- ✅ 正确
```

### 5.5 模糊查询 LIKE

| 通配符 | 说明 | 示例 |
|--------|------|------|
| `%` | 匹配任意字符出现任意次数（包括0次） | `LIKE 'a%'` 匹配以a开头 |
| `_` | 匹配任意单个字符 | `LIKE '_a_'` 匹配三个字符，中间是a |

```sql
-- 以 '张' 开头
SELECT * FROM users WHERE name LIKE '张%';

-- 包含 '明'
SELECT * FROM users WHERE name LIKE '%明%';

-- 第二个字符是 '明'
SELECT * FROM users WHERE name LIKE '_明%';

-- 姓名是两个字，第一个字是 '张'
SELECT * FROM users WHERE name LIKE '张_';

-- 不包含 'a'（MySQL）
SELECT * FROM users WHERE name NOT LIKE '%a%';

-- 转义特殊字符
SELECT * FROM users WHERE name LIKE '%\_%' ESCAPE '\';  -- 匹配包含下划线
```

### 5.6 BETWEEN AND

```sql
-- 闭区间：包含边界值
SELECT * FROM products WHERE price BETWEEN 100 AND 200;

-- 等价于
SELECT * FROM products WHERE price >= 100 AND price <= 200;

-- 日期范围
SELECT * FROM orders 
WHERE order_date BETWEEN '2024-01-01' AND '2024-12-31';

-- NOT BETWEEN
SELECT * FROM products WHERE price NOT BETWEEN 100 AND 200;
```

**优先级：BETWEEN AND 优先于 OR**

```sql
-- 先计算 BETWEEN，再 OR
SELECT * FROM products WHERE price BETWEEN 100 AND 200 OR category = 'electronics';

-- 等价于
SELECT * FROM products WHERE (price BETWEEN 100 AND 200) OR category = 'electronics';
```

## 六、LIMIT 分页

### 6.1 基本语法

```sql
-- MySQL/PostgreSQL 语法
SELECT * FROM users LIMIT 10;              -- 前10条
SELECT * FROM users LIMIT 10 OFFSET 5;     -- 跳过5条，取10条
SELECT * FROM users LIMIT 5, 10;           -- MySQL 简写：偏移量5，取10条
```

### 6.2 分页公式

```sql
-- 第n页，每页m条
SELECT * FROM users LIMIT m OFFSET (n-1)*m;

-- 示例：第3页，每页10条
SELECT * FROM users LIMIT 10 OFFSET 20;
```

### 6.3 不同数据库的分页语法

| 数据库 | 语法 |
|--------|------|
| **MySQL** | `LIMIT 10 OFFSET 5` 或 `LIMIT 5, 10` |
| **PostgreSQL** | `LIMIT 10 OFFSET 5` |
| **Oracle** | `OFFSET 5 ROWS FETCH NEXT 10 ROWS ONLY` |
| **SQL Server** | `OFFSET 5 ROWS FETCH NEXT 10 ROWS ONLY` |

## 七、字符串函数

### 7.1 常用字符串函数

| 函数 | MySQL | PostgreSQL | 说明 |
|------|-------|------------|------|
| 去除左空格 | `LTRIM()` | `LTRIM()` | 去除字符串左边空格 |
| 去除右空格 | `RTRIM()` | `RTRIM()` | 去除字符串右边空格 |
| 去除两边空格 | `TRIM()` | `TRIM()` | 去除字符串两边空格 |
| 字符串长度 | `LENGTH()` | `LENGTH()` | 返回字符数 |
| 字节长度 | `CHAR_LENGTH()` | `LENGTH()` | 返回字符数（与LENGTH相同） |
| 转大写 | `UPPER()` | `UPPER()` | 转换为大写 |
| 转小写 | `LOWER()` | `LOWER()` | 转换为小写 |
| 拼接 | `CONCAT()` | `\|\|` 或 `CONCAT()` | 拼接字符串 |

### 7.2 字符串函数示例

```sql
-- MySQL 字符串拼接
SELECT CONCAT(name, '(', email, ')') FROM users;

-- PostgreSQL 字符串拼接（推荐方式）
SELECT name || '(' || email || ')' FROM users;

-- PostgreSQL 也支持 CONCAT
SELECT CONCAT(name, '(', email, ')') FROM users;

-- 去除空格
SELECT TRIM(name) FROM users;
SELECT LTRIM(name) FROM users;
SELECT RTRIM(name) FROM users;

-- 转换大小写
SELECT UPPER(name), LOWER(email) FROM users;

-- 字符串长度
SELECT name, LENGTH(name) FROM users;

-- 截取字符串
-- MySQL
SELECT SUBSTRING(name, 1, 3) FROM users;  -- 从第1位开始，取3个字符

-- PostgreSQL
SELECT SUBSTRING(name FROM 1 FOR 3) FROM users;

-- 替换字符串
SELECT REPLACE(email, '@example.com', '@newdomain.com') FROM users;

-- 查找位置
SELECT POSITION('@' IN email) FROM users;  -- PostgreSQL
SELECT LOCATE('@', email) FROM users;      -- MySQL
```

## 八、日期时间函数

### 8.1 常用日期函数

| 函数 | MySQL | PostgreSQL | 说明 |
|------|-------|------------|------|
| 当前日期 | `CURDATE()` | `CURRENT_DATE` | 获取当前日期 |
| 当前时间 | `CURTIME()` | `CURRENT_TIME` | 获取当前时间 |
| 当前日期时间 | `NOW()` | `NOW()` | 获取当前日期时间 |
| 日期加减 | `DATE_ADD()` | `+ INTERVAL` | 日期加减 |
| 日期差 | `DATEDIFF()` | `AGE()` | 日期差 |

### 8.2 日期函数示例

```sql
-- MySQL
SELECT NOW();                    -- 2024-01-15 14:30:00
SELECT CURDATE();                -- 2024-01-15
SELECT CURTIME();                -- 14:30:00

-- 日期加减
SELECT DATE_ADD(NOW(), INTERVAL 7 DAY);      -- 加7天
SELECT DATE_SUB(NOW(), INTERVAL 1 MONTH);    -- 减1个月

-- 日期差
SELECT DATEDIFF('2024-12-31', '2024-01-01');  -- 365天

-- 格式化日期
SELECT DATE_FORMAT(NOW(), '%Y-%m-%d');       -- 2024-01-15

-- PostgreSQL
SELECT CURRENT_DATE;                          -- 2024-01-15
SELECT CURRENT_TIME;                          -- 14:30:00
SELECT NOW();                                 -- 2024-01-15 14:30:00

-- 日期加减
SELECT NOW() + INTERVAL '7 days';             -- 加7天
SELECT NOW() - INTERVAL '1 month';            -- 减1个月

-- 日期差
SELECT AGE('2024-12-31', '2024-01-01');       -- 11 mons 30 days

-- 格式化日期
SELECT TO_CHAR(NOW(), 'YYYY-MM-DD');          -- 2024-01-15
```

## 九、数据操作语句（INSERT、UPDATE、DELETE）

### 9.1 INSERT 插入数据

#### 完整插入

```sql
-- 插入所有列（必须按表定义顺序）
INSERT INTO users VALUES (1, '张三', 'zhangsan@example.com', '13800138000');

-- 指定列插入（推荐）
INSERT INTO users (id, name, email, phone) 
VALUES (1, '张三', 'zhangsan@example.com', '13800138000');
```

#### 省略列的条件

```sql
-- 以下情况可以省略列
INSERT INTO users (name, email) VALUES ('李四', 'lisi@example.com');

-- 省略的列必须满足：
-- 1. 定义为允许NULL值
-- 2. 或者有默认值（DEFAULT）
-- 3. 或者是自增列（AUTO_INCREMENT / SERIAL）

-- 示例：假设 id 是自增，phone 允许 NULL
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    email VARCHAR(100) NOT NULL,
    phone VARCHAR(20) NULL DEFAULT ''
);

-- 此时可以只插入必需的列
INSERT INTO users (name, email) VALUES ('王五', 'wangwu@example.com');
```

#### 批量插入

```sql
-- MySQL
INSERT INTO users (name, email) VALUES 
    ('张三', 'zhangsan@example.com'),
    ('李四', 'lisi@example.com'),
    ('王五', 'wangwu@example.com');

-- PostgreSQL
INSERT INTO users (name, email) VALUES 
    ('张三', 'zhangsan@example.com'),
    ('李四', 'lisi@example.com'),
    ('王五', 'wangwu@example.com');
```

#### 插入查询结果

```sql
-- 从其他表插入数据
INSERT INTO user_archive (id, name, email)
SELECT id, name, email FROM users WHERE status = 'deleted';

-- MySQL 复制表结构和数据
CREATE TABLE customers_copy AS SELECT * FROM customers;

-- 只复制结构
CREATE TABLE customers_copy AS SELECT * FROM customers WHERE 1=0;
```

### 9.2 UPDATE 更新数据

#### 基本语法

```sql
UPDATE 表名 
SET 列1 = 值1, 列2 = 值2, ...
WHERE 条件;

-- 示例
UPDATE users 
SET email = 'newemail@example.com', phone = '13900139000'
WHERE id = 1;
```

#### 注意事项

```sql
-- ⚠️ 一定要加 WHERE，否则会更新所有行！
UPDATE users SET status = 'active';  -- ❌ 危险！更新所有行

-- ✅ 正确做法
UPDATE users SET status = 'active' WHERE id = 1;

-- 更新为 NULL
UPDATE users SET phone = NULL WHERE id = 1;

-- 使用表达式更新
UPDATE products SET price = price * 1.1 WHERE category = 'electronics';

-- 多条件更新
UPDATE users 
SET status = 'active', updated_at = NOW()
WHERE status = 'inactive' AND last_login < '2024-01-01';
```

---

### 9.3 DELETE 删除数据

#### 基本语法

```sql
DELETE FROM 表名 WHERE 条件;

-- 示例
DELETE FROM users WHERE id = 1;

-- 多条件删除
DELETE FROM users WHERE status = 'deleted' AND created_at < '2023-01-01';
```

#### 注意事项

```sql
-- ⚠️ 一定要加 WHERE，否则会删除所有行！
DELETE FROM users;  -- ❌ 危险！删除所有行

-- ✅ 正确做法
DELETE FROM users WHERE id = 1;

-- 删除所有行（但保留表结构）
DELETE FROM users;
TRUNCATE TABLE users;  -- 更快，但不可回滚

-- 删除前建议先查询确认
SELECT * FROM users WHERE id = 1;  -- 先看要删什么
DELETE FROM users WHERE id = 1;     -- 再删
```

## 十、聚合函数

### 10.1 常用聚合函数

| 函数 | 说明 | 适用DISTINCT |
|------|------|--------------|
| `COUNT()` | 计数 | ✅ COUNT(DISTINCT 列) |
| `SUM()` | 求和 | ✅ SUM(DISTINCT 列) |
| `AVG()` | 平均值 | ✅ AVG(DISTINCT 列) |
| `MAX()` | 最大值 | ✅ MAX(DISTINCT 列) |
| `MIN()` | 最小值 | ✅ MIN(DISTINCT 列) |

### 10.2 聚合函数示例

```sql
-- COUNT：统计行数
SELECT COUNT(*) FROM employees;              -- 总行数
SELECT COUNT(department) FROM employees;     -- 非NULL值数量
SELECT COUNT(DISTINCT department) FROM employees;  -- 去重后的部门数量

-- SUM：求和
SELECT SUM(salary) FROM employees WHERE department = 'IT';

-- AVG：平均值
SELECT AVG(salary) FROM employees;

-- MAX/MIN：最大最小值
SELECT MAX(salary), MIN(salary) FROM employees;

-- 组合使用
SELECT 
    department,
    COUNT(*) AS emp_count,
    SUM(salary) AS total_salary,
    AVG(salary) AS avg_salary,
    MAX(salary) AS max_salary,
    MIN(salary) AS min_salary
FROM employees
GROUP BY department;
```

## 十二、表操作

### 12.1 创建表

```sql
CREATE TABLE Products (
    prod_id       CHAR(10)      NOT NULL,
    vend_id       CHAR(10)      NOT NULL,
    prod_name     CHAR(254)     NOT NULL,
    prod_price    DECIMAL(8,2)  NOT NULL,
    prod_desc     VARCHAR(1000) NULL,
    PRIMARY KEY (prod_id)
);

-- PostgreSQL 自增列
CREATE TABLE users (
    id       SERIAL PRIMARY KEY,      -- 自增主键
    name     VARCHAR(50) NOT NULL,
    email    VARCHAR(100) UNIQUE,
    status   VARCHAR(20) DEFAULT 'active'
);

-- MySQL 自增列
CREATE TABLE users (
    id       INT AUTO_INCREMENT PRIMARY KEY,  -- 自增主键
    name     VARCHAR(50) NOT NULL,
    email    VARCHAR(100) UNIQUE,
    status   VARCHAR(20) DEFAULT 'active'
);
```

### 12.2 修改表结构

```sql
-- 添加列
ALTER TABLE users ADD COLUMN age INT;
ALTER TABLE users ADD COLUMN phone VARCHAR(20);

-- 修改列
ALTER TABLE users MODIFY COLUMN name VARCHAR(100);        -- MySQL
ALTER TABLE users ALTER COLUMN name TYPE VARCHAR(100);    -- PostgreSQL

-- 删除列
ALTER TABLE users DROP COLUMN age;

-- 添加主键
ALTER TABLE users ADD PRIMARY KEY (id);

-- 添加外键
ALTER TABLE orders ADD CONSTRAINT fk_user
FOREIGN KEY (user_id) REFERENCES users(id);

-- 添加索引
ALTER TABLE users ADD INDEX idx_email (email);

-- 修改表名
ALTER TABLE users RENAME TO customers;         -- MySQL
ALTER TABLE users RENAME TO new_users;         -- PostgreSQL
RENAME TABLE users TO new_users;               -- MySQL
```

### 12.3 删除表

```sql
-- 删除表（数据和结构都删除）
DROP TABLE users;

-- 删除前检查是否存在
DROP TABLE IF EXISTS users;

-- 只删除数据，保留表结构
DELETE FROM users;      -- 可回滚
TRUNCATE TABLE users;   -- 不可回滚，但更快
```

## 十三、约束

### 13.1 约束类型

| 约束 | 说明 | 示例 |
|------|------|------|
| `PRIMARY KEY` | 主键，唯一标识 | `id INT PRIMARY KEY` |
| `FOREIGN KEY` | 外键，关联其他表 | `user_id INT REFERENCES users(id)` |
| `NOT NULL` | 非空约束 | `name VARCHAR(50) NOT NULL` |
| `UNIQUE` | 唯一约束 | `email VARCHAR(100) UNIQUE` |
| `CHECK` | 检查约束 | `age INT CHECK(age >= 18)` |
| `DEFAULT` | 默认值 | `status VARCHAR(20) DEFAULT 'active'` |

### 13.2 约束示例

```sql
CREATE TABLE employees (
    id         INT PRIMARY KEY,
    name       VARCHAR(50) NOT NULL,
    email      VARCHAR(100) UNIQUE,
    age        INT CHECK (age >= 18 AND age <= 65),
    salary     DECIMAL(10,2) CHECK (salary > 0),
    department VARCHAR(50) NOT NULL,
    manager_id INT,
    
    FOREIGN KEY (manager_id) REFERENCES employees(id),
    CHECK (email LIKE '%@%')
);

-- MySQL CHECK 约束（部分版本支持）
ALTER TABLE employees
ADD CONSTRAINT chk_email CHECK (email LIKE '%@%');
```

## 本节面试考点

| 考点 | 答案要点 |
|------|----------|
| SQL执行顺序 | FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT |
| DISTINCT作用 | 作用于所有列，不能用于COUNT(*) |
| 为什么不用SELECT * | 性能差、不灵活、表结构变化可能出错 |
| NULL判断 | 必须用IS NULL或IS NOT NULL |
| LIKE通配符 | `%`匹配任意字符，`_`匹配单个字符 |
| LIMIT语法 | `LIMIT n OFFSET m` 或 `LIMIT m, n`（MySQL） |
| 聚合函数 | COUNT、SUM、AVG、MAX、MIN，可用DISTINCT |
| 自增列 | MySQL: `AUTO_INCREMENT`，PostgreSQL: `SERIAL` |
| DELETE vs TRUNCATE | DELETE可回滚，TRUNCATE不可回滚但更快 |
