# SQL 学习笔记 - 事务与游标

## 一、事务（Transaction）

### 1.1 事务核心概念

| 概念 | 说明 |
|------|------|
| **事务** | 一组SQL语句，要么全部成功，要么全部失败 |
| **回退** | 撤销指定SQL语句的过程 |
| **提交** | 将未存储的SQL语句结果写入数据库表 |
| **保留点** | 事务处理中设置的临时占位符，可以回退到指定位置 |

---

### 1.2 ACID 特性

| 特性 | 说明 |
|------|------|
| **原子性**（Atomicity） | 事务中的操作要么全部成功，要么全部失败 |
| **一致性**（Consistency） | 事务执行前后，数据库状态保持一致 |
| **隔离性**（Isolation） | 多个事务并发执行时，互不干扰 |
| **持久性**（Durability） | 事务提交后，结果永久保存 |

---

### 1.3 事务基本语法

```sql
-- MySQL
START TRANSACTION;
-- 或
BEGIN;

-- SQL 语句
UPDATE accounts SET balance = balance - 100 WHERE id = 1;
UPDATE accounts SET balance = balance + 100 WHERE id = 2;

-- 提交或回退
COMMIT;   -- 提交
ROLLBACK; -- 回退

-- PostgreSQL
BEGIN;
-- SQL 语句
UPDATE accounts SET balance = balance - 100 WHERE id = 1;
UPDATE accounts SET balance = balance + 100 WHERE id = 2;

COMMIT;   -- 提交
ROLLBACK; -- 回退
```

### 1.4 事务处理示例

#### 简单转账

```sql
-- MySQL
START TRANSACTION;

-- 转出账户扣款
UPDATE accounts SET balance = balance - 1000 WHERE id = 1;

-- 转入账户加钱
UPDATE accounts SET balance = balance + 1000 WHERE id = 2;

-- 检查余额是否合法
SELECT balance FROM accounts WHERE id = 1;

-- 确认无误后提交
COMMIT;

-- 如果有问题则回滚
-- ROLLBACK;

-- PostgreSQL
BEGIN;
UPDATE accounts SET balance = balance - 1000 WHERE id = 1;
UPDATE accounts SET balance = balance + 1000 WHERE id = 2;
COMMIT;
```

#### 复杂事务（带错误处理）

```sql
-- MySQL 带错误处理
DELIMITER $$
CREATE PROCEDURE SafeTransfer(
    IN fromId INT,
    IN toId INT,
    IN amount DECIMAL(10,2),
    OUT result VARCHAR(100)
)
BEGIN
    DECLARE from_balance DECIMAL(10,2);
    DECLARE EXIT HANDLER FOR SQLEXCEPTION
    BEGIN
        ROLLBACK;
        SET result = '转账失败：系统错误';
    END;
    
    -- 检查余额
    SELECT balance INTO from_balance FROM accounts WHERE id = fromId;
    
    IF from_balance < amount THEN
        SET result = '转账失败：余额不足';
        RETURN;
    END IF;
    
    -- 开始事务
    START TRANSACTION;
    
    -- 扣款
    UPDATE accounts SET balance = balance - amount WHERE id = fromId;
    
    -- 加钱
    UPDATE accounts SET balance = balance + amount WHERE id = toId;
    
    -- 记录转账日志
    INSERT INTO transfer_logs (from_id, to_id, amount, transfer_time)
    VALUES (fromId, toId, amount, NOW());
    
    -- 提交
    COMMIT;
    SET result = '转账成功';
END$$
DELIMITER ;

-- 调用
CALL SafeTransfer(1, 2, 1000, @result);
SELECT @result;

-- PostgreSQL 版本
CREATE OR REPLACE FUNCTION safe_transfer(
    from_id INT,
    to_id INT,
    amount NUMERIC(10,2)
) RETURNS VARCHAR AS $$
DECLARE
    from_balance NUMERIC(10,2);
BEGIN
    -- 检查余额
    SELECT balance INTO from_balance FROM accounts WHERE id = from_id;
    
    IF from_balance < amount THEN
        RAISE EXCEPTION '转账失败：余额不足';
    END IF;
    
    -- 开始事务
    BEGIN
        -- 扣款
        UPDATE accounts SET balance = balance - amount WHERE id = from_id;
        
        -- 加钱
        UPDATE accounts SET balance = balance + amount WHERE id = to_id;
        
        -- 记录转账日志
        INSERT INTO transfer_logs (from_id, to_id, amount, transfer_time)
        VALUES (from_id, to_id, amount, NOW());
        
        COMMIT;
        RETURN '转账成功';
    EXCEPTION
        WHEN OTHERS THEN
            ROLLBACK;
            RAISE EXCEPTION '转账失败：% 的详细信息', SQLERRM;
    END;
END;
$$ LANGUAGE plpgsql;
```

### 1.5 保留点（SAVEPOINT）

保留点允许在事务中设置标记，可以回退到指定位置，而不是回退整个事务。

```sql
-- MySQL 保留点
START TRANSACTION;

INSERT INTO orders (user_id, amount) VALUES (1, 100);
SAVEPOINT save1;  -- 设置保留点

INSERT INTO order_items (order_id, product_id, quantity) VALUES (LAST_INSERT_ID(), 1, 2);
SAVEPOINT save2;

-- 发生错误，回退到保留点
ROLLBACK TO SAVEPOINT save2;  -- 只撤销最后一条 INSERT

-- 继续执行
INSERT INTO order_items (order_id, product_id, quantity) VALUES (LAST_INSERT_ID(), 2, 1);

COMMIT;

-- PostgreSQL 保留点
BEGIN;

INSERT INTO orders (user_id, amount) VALUES (1, 100);
SAVEPOINT save1;

INSERT INTO order_items (order_id, product_id, quantity) VALUES (
    (SELECT MAX(id) FROM orders), 1, 2
);
SAVEPOINT save2;

-- 回退到保留点
ROLLBACK TO SAVEPOINT save2;

-- 继续执行
INSERT INTO order_items (order_id, product_id, quantity) VALUES (
    (SELECT MAX(id) FROM orders), 2, 1
);

COMMIT;
```

### 1.6 事务的隔离级别

| 隔离级别 | 脏读 | 不可重复读 | 幻读 | 说明 |
|----------|------|------------|------|------|
| **READ UNCOMMITTED** | ✅ | ✅ | ✅ | 读未提交 |
| **READ COMMITTED** | ❌ | ✅ | ✅ | 读已提交 |
| **REPEATABLE READ** | ❌ | ❌ | ✅ | 可重复读（MySQL 默认） |
| **SERIALIZABLE** | ❌ | ❌ | ❌ | 串行化 |

**并发问题说明：**

| 问题 | 说明 |
|------|------|
| **脏读** | 读取了未提交的数据 |
| **不可重复读** | 同一事务中，两次读取同一数据结果不同 |
| **幻读** | 同一事务中，两次查询结果集不同（新增或删除） |

---

### 1.7 设置隔离级别

```sql
-- MySQL 设置隔离级别
SET TRANSACTION ISOLATION LEVEL READ COMMITTED;
SET TRANSACTION ISOLATION LEVEL REPEATABLE READ;
SET TRANSACTION ISOLATION LEVEL SERIALIZABLE;

-- 或者在配置文件中设置
[mysqld]
transaction-isolation = READ-COMMITTED

-- PostgreSQL 设置隔离级别
SET TRANSACTION ISOLATION LEVEL READ COMMITTED;
SET TRANSACTION ISOLATION LEVEL REPEATABLE READ;
SET TRANSACTION ISOLATION LEVEL SERIALIZABLE;

-- 查看当前隔离级别
-- MySQL
SELECT @@transaction_isolation;

-- PostgreSQL
SHOW transaction_isolation;
```

### 1.8 事务的隔离级别示例

```sql
-- 演示脏读（READ UNCOMMITTED）
-- 事务A
SET TRANSACTION ISOLATION LEVEL READ UNCOMMITTED;
START TRANSACTION;
UPDATE accounts SET balance = balance - 1000 WHERE id = 1;  -- 未提交
-- 此时事务B（READ UNCOMMITTED）能读到这个未提交的修改

-- 演示不可重复读（READ COMMITTED）
-- 事务A
SET TRANSACTION ISOLATION LEVEL READ COMMITTED;
START TRANSACTION;
SELECT balance FROM accounts WHERE id = 1;  -- 第一次读取

-- 事务B：更新并提交
UPDATE accounts SET balance = balance + 1000 WHERE id = 1;
COMMIT;

-- 事务A：再次读取，结果不同
SELECT balance FROM accounts WHERE id = 1;  -- 第二次读取

-- 演示幻读（REPEATABLE READ vs SERIALIZABLE）
-- 事务A
SET TRANSACTION ISOLATION LEVEL REPEATABLE READ;
START TRANSACTION;
SELECT * FROM accounts WHERE balance > 1000;  -- 第一次查询

-- 事务B：插入新记录
INSERT INTO accounts (id, name, balance) VALUES (10, 'New', 2000);
COMMIT;

-- 事务A：再次查询，可能看到新记录（幻读）
SELECT * FROM accounts WHERE balance > 1000;  -- 第二次查询
```

### 1.9 事务失效场景

```sql
-- ❌ 事务失效场景

-- 1. MyISAM 引擎不支持事务（必须用 InnoDB）
CREATE TABLE test (id INT PRIMARY KEY) ENGINE=MyISAM;  -- 不支持事务

-- 2. DDL 语句不能回退
START TRANSACTION;
CREATE TABLE test (id INT PRIMARY KEY);  -- 不能回退
DROP TABLE test;                          -- 不能回退
ROLLBACK;  -- 无效

-- 3. 部分语句无法回退
START TRANSACTION;
TRUNCATE TABLE test;  -- MySQL 中无法回退
ROLLBACK;  -- 无效

-- 4. 未正确开启事务
UPDATE accounts SET balance = balance - 100 WHERE id = 1;  -- 自动提交
ROLLBACK;  -- 无效

-- 5. 错误被捕获但未回滚
BEGIN;
UPDATE accounts SET balance = balance - 100 WHERE id = 1;
-- 发生错误但被处理
SELECT 'Error handled';
-- 忘记 ROLLBACK
COMMIT;  -- 可能提交了部分数据
```

## 二、游标（Cursor）

### 2.1 什么是游标

SQL 是处理"集合"的，而游标是用来处理"集合中的每一行"的。它像一个"指针"，可以一行一行地读取和操作查询结果。

**为什么需要游标？**
- 对每行数据调用另一个存储过程
- 根据当前行计算后，更新另一些数据
- 批量处理数据

**注意：游标性能较差，优先考虑集合操作！**

---

### 2.2 游标生命周期

```
1. 声明（DECLARE）：定义游标，绑定 SELECT 语句
2. 打开（OPEN）：执行 SELECT，准备结果集
3. 读取（FETCH）：获取一行数据
4. 处理（PROCESS）：业务逻辑
5. 关闭（CLOSE）：关闭游标
6. 释放（DEALLOCATE）：释放资源
```

---

### 2.3 MySQL 游标示例

```sql
-- 给所有员工涨薪1000
DELIMITER $$
CREATE PROCEDURE RaiseAllSalary()
BEGIN
    DECLARE done INT DEFAULT FALSE;
    DECLARE emp_id INT;
    DECLARE emp_name VARCHAR(50);
    DECLARE emp_salary DECIMAL(10,2);
    
    -- 声明游标
    DECLARE cur CURSOR FOR 
        SELECT id, name, salary FROM employees;
    
    -- 声明结束处理程序
    DECLARE CONTINUE HANDLER FOR NOT FOUND SET done = TRUE;
    
    -- 打开游标
    OPEN cur;
    
    -- 循环读取
    read_loop: LOOP
        FETCH cur INTO emp_id, emp_name, emp_salary;
        
        -- 判断是否结束
        IF done THEN
            LEAVE read_loop;
        END IF;
        
        -- 处理逻辑：涨薪
        UPDATE employees 
        SET salary = emp_salary + 1000 
        WHERE id = emp_id;
        
        -- 输出处理信息（可选）
        SELECT CONCAT('涨薪: ', emp_name, ' ', emp_salary, ' -> ', emp_salary + 1000) AS info;
    END LOOP;
    
    -- 关闭游标
    CLOSE cur;
END$$
DELIMITER ;

-- 调用
CALL RaiseAllSalary();
```

---

### 2.4 PostgreSQL 游标示例

```sql
-- 给所有员工涨薪1000
CREATE OR REPLACE FUNCTION raise_all_salary()
RETURNS VOID AS $$
DECLARE
    emp_record RECORD;
    new_salary NUMERIC(10,2);
BEGIN
    -- 遍历员工
    FOR emp_record IN SELECT id, name, salary FROM employees
    LOOP
        -- 计算新工资
        new_salary := emp_record.salary + 1000;
        
        -- 更新工资
        UPDATE employees SET salary = new_salary WHERE id = emp_record.id;
        
        -- 输出信息（调试用）
        RAISE NOTICE '涨薪: %, % -> %', 
            emp_record.name, emp_record.salary, new_salary;
    END LOOP;
    
    RETURN;
END;
$$ LANGUAGE plpgsql;

-- 调用
SELECT raise_all_salary();
```

### 2.5 带条件的游标处理

```sql
-- MySQL：给工作超过5年的员工涨薪20%
DELIMITER $$
CREATE PROCEDURE RaiseLongTermEmployees()
BEGIN
    DECLARE done INT DEFAULT FALSE;
    DECLARE emp_id INT;
    DECLARE emp_years INT;
    DECLARE emp_salary DECIMAL(10,2);
    
    -- 声明游标（带条件）
    DECLARE cur CURSOR FOR 
        SELECT id, years_of_service, salary 
        FROM employees 
        WHERE years_of_service > 5;
    
    DECLARE CONTINUE HANDLER FOR NOT FOUND SET done = TRUE;
    
    OPEN cur;
    
    read_loop: LOOP
        FETCH cur INTO emp_id, emp_years, emp_salary;
        
        IF done THEN
            LEAVE read_loop;
        END IF;
        
        -- 根据工龄计算涨幅
        DECLARE new_salary DECIMAL(10,2);
        DECLARE rate DECIMAL(3,2);
        
        IF emp_years >= 10 THEN
            SET rate = 0.30;
        ELSEIF emp_years >= 7 THEN
            SET rate = 0.25;
        ELSE
            SET rate = 0.20;
        END IF;
        
        SET new_salary = emp_salary * (1 + rate);
        
        -- 更新工资
        UPDATE employees 
        SET salary = new_salary 
        WHERE id = emp_id;
    END LOOP;
    
    CLOSE cur;
END$$
DELIMITER ;

-- PostgreSQL 版本
CREATE OR REPLACE FUNCTION raise_long_term_employees()
RETURNS VOID AS $$
DECLARE
    emp_record RECORD;
    new_salary NUMERIC(10,2);
    rate NUMERIC(3,2);
BEGIN
    FOR emp_record IN 
        SELECT id, years_of_service, salary 
        FROM employees 
        WHERE years_of_service > 5
    LOOP
        -- 根据工龄计算涨幅
        IF emp_record.years_of_service >= 10 THEN
            rate := 0.30;
        ELSIF emp_record.years_of_service >= 7 THEN
            rate := 0.25;
        ELSE
            rate := 0.20;
        END IF;
        
        new_salary := emp_record.salary * (1 + rate);
        
        -- 更新工资
        UPDATE employees SET salary = new_salary WHERE id = emp_record.id;
        
        RAISE NOTICE '涨薪: ID=%, 工龄=%, 涨幅=%', 
            emp_record.id, emp_record.years_of_service, rate;
    END LOOP;
END;
$$ LANGUAGE plpgsql;
```

### 2.6 游标种类

| 种类 | 说明 | 性能 |
|------|------|------|
| **只读游标** | 默认，不能修改数据 | 最好 |
| **可滚动游标** | 可以前进、后退、跳转 | 较慢 |
| **静态游标** | 结果集固定 | 稳定但慢 |
| **动态游标** | 结果集实时更新 | 较快 |
| **键集游标** | 基于主键 | 平衡 |

```sql
-- MySQL 只读游标
DECLARE cur CURSOR FOR SELECT * FROM employees;

-- PostgreSQL 可滚动游标
CREATE OR REPLACE FUNCTION scrollable_cursor_demo()
RETURNS VOID AS $$
DECLARE
    cur CURSOR FOR SELECT * FROM employees;
    emp_record RECORD;
BEGIN
    OPEN cur;
    
    -- 移动到第一行
    MOVE FIRST IN cur;
    FETCH cur INTO emp_record;
    RAISE NOTICE 'First: %', emp_record.name;
    
    -- 移动到最后一行
    MOVE LAST IN cur;
    FETCH cur INTO emp_record;
    RAISE NOTICE 'Last: %', emp_record.name;
    
    -- 向前移动
    MOVE PRIOR IN cur;
    FETCH cur INTO emp_record;
    RAISE NOTICE 'Prior: %', emp_record.name;
    
    -- 移动到第5行
    MOVE ABSOLUTE 5 IN cur;
    FETCH cur INTO emp_record;
    RAISE NOTICE '5th: %', emp_record.name;
    
    CLOSE cur;
END;
$$ LANGUAGE plpgsql;
```

### 2.7 游标性能优化

```sql
-- ❌ 低效：使用游标逐行更新
DELIMITER $$
CREATE PROCEDURE InefficientUpdate()
BEGIN
    DECLARE done INT DEFAULT FALSE;
    DECLARE emp_id INT;
    DECLARE emp_salary DECIMAL(10,2);
    
    DECLARE cur CURSOR FOR SELECT id, salary FROM employees;
    DECLARE CONTINUE HANDLER FOR NOT FOUND SET done = TRUE;
    
    OPEN cur;
    
    read_loop: LOOP
        FETCH cur INTO emp_id, emp_salary;
        IF done THEN LEAVE read_loop; END IF;
        
        UPDATE employees SET salary = emp_salary * 1.1 WHERE id = emp_id;
    END LOOP;
    
    CLOSE cur;
END$$
DELIMITER ;

-- ✅ 高效：使用单条 UPDATE
CREATE PROCEDURE EfficientUpdate()
BEGIN
    UPDATE employees SET salary = salary * 1.1;
END$$
DELIMITER ;

-- PostgreSQL 版本对比
-- ❌ 低效
CREATE OR REPLACE FUNCTION inefficient_update()
RETURNS VOID AS $$
DECLARE
    emp_record RECORD;
BEGIN
    FOR emp_record IN SELECT id, salary FROM employees
    LOOP
        UPDATE employees SET salary = emp_record.salary * 1.1 WHERE id = emp_record.id;
    END LOOP;
END;
$$ LANGUAGE plpgsql;

-- ✅ 高效
CREATE OR REPLACE FUNCTION efficient_update()
RETURNS VOID AS $$
BEGIN
    UPDATE employees SET salary = salary * 1.1;
END;
$$ LANGUAGE plpgsql;
```

### 2.8 游标使用建议

| 建议 | 说明 |
|------|------|
| **优先集合操作** | 能用 UPDATE/JOIN 解决就不用游标 |
| **尽快释放** | 用完立即 CLOSE 和 DEALLOCATE |
| **限制数据量** | 游标前先过滤数据 |
| **避免嵌套** | 游标嵌套性能极差 |
| **添加日志** | 便于调试和监控 |
