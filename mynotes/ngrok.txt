Ngrok 内网穿透工具 
正常网络：内网 → 外网（正向，NAT 允许）
穿透网络：外网 → 中转服务 → 预先建好的长连接 → 内网（反向，绕过 NAT 限制）

1.配置Authtoken
ngrok config add-authtoken $YOUR_AUTHTOKEN

2.查看开发域名

3.开启穿透
Vite有黑名单机制,默认不允许对应的外网穿透
需要在vite.config对应文件中配置
server: 
  {
    // 放行你的ngrok域名，* 代表放行所有域名
    allowedHosts: ['geranium-impromptu-zoning.ngrok-free.dev']
    // 懒人写法：allowedHosts: 'all'
  }

ngrok http <port> // 默认是开发域名关联本地
