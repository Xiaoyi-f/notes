# 01 - 认识你的"搭档"：常见嵌入式芯片和开发板

---

## 一、什么是嵌入式系统？

**一句话理解**：嵌入式系统就是「藏在各种设备里的小型电脑」，它不像你的手机、电脑那样有屏幕和键盘，但它在做重要的事情。

```
你的手机 📱            嵌入式系统 🔧
├─ 大屏幕              ├─ 没有屏幕（或很小）
├─ 能装各种App         ├─ 只做一件事（或几件事）
├─ 8核处理器           ├─ 单核/双核，主频很低
├─ 8GB内存             ├─ 几十KB内存
├─ 256GB存储           ├─ 几百KB存储
└─ 能运行微信/游戏      └─ 运行温度采集、电机控制
```

**举例**：
- 智能手环里的芯片 → 计步、测心率
- 空调遥控器里的芯片 → 发红外信号
- 汽车里的芯片 → 控制发动机、刹车
- 工厂传感器里的芯片 → 读取温度、湿度、压力

## 二、常见嵌入式芯片（MCU）

### 1. ESP32（乐鑫）—— 最适合初学者的WiFi芯片

```
┌─────────────────────────────────────┐
│           ESP32                      │
│                                      │
│  主频：240MHz（双核）                 │
│  内存：520KB SRAM                    │
│  Flash：4MB/8MB/16MB                 │
│                                      │
│  内置WiFi + 蓝牙                      │
│  内置ADC（模拟输入）                   │
│  价格：¥10-20                        │
│                                      │
│  适用场景：IoT设备、智能家居、          │
│           数据采集+联网               │
└─────────────────────────────────────┘
```

**为什么推荐先学它**：
- 便宜（十几块钱）
- 功能全（WiFi+蓝牙+各种接口）
- 社区活跃（资料多、例程多）
- Arduino IDE 就能开发（门槛低）

---

### 2. STM32（意法半导体）—— 工业界的王者

```
┌─────────────────────────────────────┐
│         STM32F103（经典款）           │
│                                      │
│  主频：72MHz（单核）                  │
│  内存：20KB SRAM                     │
│  Flash：64KB/128KB                   │
│                                      │
│  没有内置WiFi/蓝牙                    │
│  需要外接通信模组                     │
│  价格：¥5-15                         │
│                                      │
│  适用场景：工业控制、                  │
│           电机驱动、汽车电子           │
└─────────────────────────────────────┘
```

**为什么工业界爱用它**：
- 稳定、可靠（-40°C到85°C都能工作）
- 实时性好（响应速度快，精确到微秒级）
- 系列丰富（从低端到高端几百种型号）

---

### 3. 树莓派（Raspberry Pi）—— 微型Linux电脑

```
┌─────────────────────────────────────┐
│        树莓派 Pico / Zero / 4B       │
│                                      │
│  主频：1.5GHz（4核）                  │
│  内存：512MB ~ 8GB                   │
│  存储：SD卡（可换）                   │
│                                      │
│  运行完整的Linux系统                  │
│  可以跑Python、Node.js                │
│  价格：¥35-600                       │
│                                      │
│  适用场景：边缘计算网关、              │
│           图像识别、数据汇聚           │
└─────────────────────────────────────┘
```

**树莓派和普通MCU的区别**：

| | 树莓派 | ESP32/STM32 |
|--|--------|-------------|
| 操作系统 | 跑Linux | 裸机或RTOS |
| 编程语言 | Python/Node/C | C/C++ |
| 启动时间 | 几十秒 | 几百毫秒 |
| 实时性 | 差（操作系统调度） | 好（直接控制硬件） |
| 功耗 | 几瓦 | 几十毫瓦 |
| 成本 | 较高 | 很低 |

**在系统中的角色**：
- 树莓派 → 网关/边缘设备（收集多个传感器数据，处理后上传云端）
- ESP32/STM32 → 终端设备（采集传感器、控制执行器）

## 三、开发板是什么？

**开发板 = 芯片 + 外围电路 + 调试接口**，让你能方便地编程和调试。

```
┌────────────────────────────────────────────┐
│              ESP32开发板                     │
│                                            │
│   ┌─────────────┐                          │
│   │   ESP32芯片  │ ← 核心，执行你的程序      │
│   └─────────────┘                          │
│                                            │
│   ┌─────────────┐                          │
│   │  USB转串口   │ ← 连接电脑，传程序+看输出  │
│   └─────────────┘                          │
│                                            │
│   ┌──────┐ ┌──────┐ ┌──────┐              │
│   │GPIO引脚│ │GPIO引脚│ │GPIO引脚│ ← 接传感器/执行器 │
│   └──────┘ └──────┘ └──────┘              │
│                                            │
│   ┌─────────────┐                          │
│   │   电源模块   │ ← USB供电或外接电源       │
│   └─────────────┘                          │
│                                            │
│   ┌──────┐ ┌──────┐                        │
│   │ 按钮  │ │ LED  │ ← 方便测试              │
│   └──────┘ └──────┘                        │
│                                            │
└────────────────────────────────────────────┘
```

**常见的ESP32开发板型号**：
- ESP32-DevKitC（经典款，推荐）
- ESP32-S3-DevKitC（带AI加速，性能好）
- ESP32-C3-DevKitM（便宜，RISC-V架构）

## 四、你需要知道的硬件参数

### 1. 主频（MHz/GHz）

```
主频 = CPU每秒能执行多少条指令

ESP32: 240MHz  → 每秒 2.4亿次操作
STM32: 72MHz   → 每秒 7200万次操作
树莓派: 1.5GHz → 每秒 15亿次操作
你的电脑: 3GHz  → 每秒 30亿次操作

影响：主频越高，处理越快，但功耗也越大
```

### 2. 内存（RAM / SRAM）

```
内存 = 程序运行时临时存储数据的地方

ESP32:   520KB  → 能同时存约 520,000 个字节的数据
STM32:    20KB  → 能同时存约 20,000 个字节的数据
你的手机: 8GB   → 能同时存约 8,000,000,000 个字节

对比：
- 一个 JSON 字符串 '{"temp":25.5}' ≈ 16 字节
- 一张 100x100 像素的图片 ≈ 30,000 字节
- 所以 ESP32 能存几百条传感器数据，但存不了图片
```

**关键认知**：嵌入式设备的内存很小，你不能让设备缓存太多数据！

### 3. Flash（程序存储）

```
Flash = 存储程序代码的地方（类似电脑的硬盘）

ESP32:   4MB  → 程序最大约 4MB
STM32: 128KB → 程序最大约 128KB
你的手机: 256GB

对比：
- 一个简单的传感器程序 ≈ 100KB
- 带WiFi联网的程序 ≈ 500KB
- 带图片显示的GUI程序 ≈ 1MB+
```

### 4. GPIO（通用输入输出引脚）

```
GPIO = General Purpose Input/Output
      通用     目的     输入/输出

┌──────────────────────────────────────┐
│           ESP32芯片                    │
│                                       │
│   GPIO0  ─────► 可以接按钮（输入）      │
│   GPIO1  ─────► 可以接LED（输出）       │
│   GPIO2  ─────► 可以接温度传感器         │
│   GPIO3  ─────► 可以接继电器            │
│   GPIO4  ─────► 可以接UART_TX          │
│   GPIO5  ─────► 可以接UART_RX          │
│   ...                                 │
│                                       │
│   每个GPIO引脚都可以配置为：             │
│   - 输入：读取外部信号（高/低电平）      │
│   - 输出：控制外部设备（高/低电平）      │
│   - 特殊功能：UART/I2C/SPI/PWM/ADC      │
└──────────────────────────────────────┘
```

**引脚功能速查**：

| 功能 | 说明 | 例子 |
|------|------|------|
| GPIO输入 | 读取按钮状态 | 判断按钮是否按下 |
| GPIO输出 | 控制LED开关 | LED亮/灭 |
| ADC | 模拟信号转数字 | 读取温度传感器电压 |
| PWM | 脉冲宽度调制 | 调节LED亮度、电机转速 |
| UART | 串口通信 | 和电脑/其他芯片通信 |
| I2C | 两线总线 | 接温度/湿度传感器 |
| SPI | 四线总线 | 接显示屏/SD卡 |

## 五、资源受限思维——你做系统设计时的核心约束

```
服务器程序员思维：         嵌入式程序员思维：

"内存不够？加内存条啊"     "总共就20KB，一个字节都不能浪费"
"速度慢？上云服务器啊"      "72MHz，每个时钟周期都要精打细算"
"功耗高？插电源啊"          "电池供电，必须休眠90%的时间"
"断网？重连就行"            "没有网络，数据先存在本地"
"程序大？压缩一下"          "128KB Flash，每个函数都要省"
```

**你在设计通信协议和系统架构时必须考虑**：

1. **数据量不能太大** → 设备内存装不下
2. **通信不能太频繁** → WiFi模组耗电快
3. **指令要简单** → 设备处理能力有限
4. **要有容错** → 网络可能随时断
5. **要有缓存策略** → 断网时数据不能丢
